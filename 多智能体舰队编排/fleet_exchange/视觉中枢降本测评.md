## 二、Ollama 本地视觉部署实操

### 2.1 服务启动检查

```bash
# 检查 Ollama 是否在运行
curl -s http://127.0.0.1:11434/api/tags

# 如果未响应，需要启动 Ollama 服务：
# Windows: 从开始菜单启动 Ollama，或运行 ollama serve
# 默认监听 127.0.0.1:11434
```

### 2.2 推荐模型组合

| 模型 | 体量 | 强项 | 部署命令 | 显存需求 | 适用场景 |
|------|------|------|---------|---------|---------|
| **MiniCPM-V 4.6** | ~3GB | Agent 视觉首选，token 极省（比大模型省 20–40×） | `ollama pull minicpm-v` | ~4GB VRAM | **日常截图解析、UI识别、Agent循环** |
| **Qwen2.5-VL-7B** | ~5GB | 中文 OCR / 文档 / 表格最强，输出干净 JSON | `ollama pull qwen2.5vl:7b` | ~8GB VRAM | 复杂文档、表单、密集文字 |
| LLaVA 7B (备选) | ~4GB | 通用视觉对话兜底 | `ollama pull llava:7b` | ~6GB VRAM | 通用场景备用 |

### 2.3 一键部署脚本

```bash
#!/bin/bash
# Ollama 视觉模型一键部署
echo "[1/3] 检查 Ollama 服务..."
if ! curl -s http://127.0.0.1:11434/api/tags >/dev/null 2>&1; then
  echo "[ERROR] Ollama 未运行！请先启动 Ollama 应用"
  exit 1
fi
echo "[OK] Ollama 在线"

echo "[2/3] 拉取 MiniCPM-V (日常截图)..."
ollama pull minicpm-v

echo "[3/3] 拉取 Qwen2.5-VL-7B (中文文档)..."
ollama pull qwen2.5vl:7b

echo ""
echo "[DONE] 视觉模型部署完成！"
echo "已安装模型："
ollama list
```

## 三、WorkBuddy 对接 Ollama 视觉的配置方式

### 3.1 Ollama API 格式（OpenAI 兼容）

Ollama 提供 OpenAI 兼容的 `/v1/chat/completions` 端点：

```bash
# 用 MiniCPM-V 解析图片（base64 编码）
curl -s http://127.0.0.1:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minicpm-v",
    "messages": [
      {
        "role": "user",
        "content": [
          {"type": "text", "text": "描述这张截图的内容"},
          {"type": "image_url", "image_url": {"url": "data:image/png;base64,<BASE64_DATA>"}}
        ]
      }
    ]
  }'
```

### 3.2 WorkBuddy 集成方案

| 方案 | 说明 | 改动量 |
|------|------|--------|
| **A. MCP Connector** | 安装 Ollama MCP Server，WorkBuddy 直接调用 | 最小，推荐 |
| **B. Skill 封装** | 创建 ollama-vision skill，封装图像解析逻辑 | 中等 |
| **C. HTTP 直调** | Bash/Curl 直接请求 11434 端点 | 快速但不够优雅 |

### 3.3 视觉分流路由

```
用户截图输入
    │
    ├──→ Ollama 本地(minicpm-v/qwen2.5vl)  ← 日常主力（零成本）
    │     ↓ 解析失败或精度不足
    ├──→ HY3（WorkBuddy 原始视觉）         ← 备援（消耗额度）
    │     ↓ 仍不足
    └──→ Marvis（若已接入）                 ← 兜底
```

## 五、双冗余切换开关配置建议

在 `fleet_exchange/` 下创建 `vision_config.json`：

```json
{
  "version": "1.0",
  "active_provider": "ollama",
  "fallback_chain": ["hy3", "marvis"],
  "providers": {
    "ollama": {
      "endpoint": "http://127.0.0.1:11434",
      "models": {
        "default": "minicpm-v",
        "ocr_fallback": "qwen2.5vl:7b"
      },
      "enabled": true
    },
    "hy3": {
      "endpoint": "native_workbuddy",
      "enabled": true,
      "note": "原始视觉大脑，作为 fallback"
    },
    "marvis": {
      "endpoint": "",
      "enabled": false,
      "note": "待接入"
    }
  }
}
```

切换方式：修改 `"active_provider"` 字段即可一键切换视觉中枢。
