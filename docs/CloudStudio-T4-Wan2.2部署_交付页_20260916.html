一句话结论

能部署 Cloud Studio T4 跑 ComfyUI + Wan2.2 完全可行。

但原脚本会挂 你给的那份脚本有 5 处会直接跑失败，其中 3 处会让实例空转烧机时。

预期要下调 「10 秒视频 3 分钟/条」在 T4 上做不到——按这个预期批量会烧光额度。真实档位见下方预算表。

① 原脚本 5 处必修（附实测证据）

❌ 错误 1 · Wan2.2 的 ComfyUI 插件仓库不存在
你写的 git clone …/Wan-Video/Wan2.2-ComfyUI
实测 HTTP 404 —— 仓库不存在。
真相：ComfyUI 已原生内置 Wan2.2 支持（自带 Wan22ImageToVideoLatent 等节点），不需要任何第三方插件。
❌ 错误 2 · 模型仓名不存在，权重必然下载失败
你写的 snapshot_download('Wan-Video/Wan2.2-5B') —— 该仓不存在。
正确来源与体积（实测）：
文件大小落位目录来源仓
wan2.2_ti2v_5B_fp16.safetensors9.31 GBmodels/diffusion_models/Comfy-Org/Wan_2.2_ComfyUI_Repackaged
wan2.2_vae.safetensors1.31 GBmodels/vae/Comfy-Org/Wan_2.2_ComfyUI_Repackaged
umt5_xxl_fp8_e4m3fn_scaled.safetensors6.27 GBmodels/text_encoders/Comfy-Org/Wan_2.1_ComfyUI_repackaged ← 注意是 2.1 仓
合计 16.89 GB，不是你说的「约 9.8G」——9.8G 只是主模型那一个文件。
❌ 错误 3 · HuggingFace 直连国内不通（这条最烧钱）
实测（禁用代理直连）：
huggingface.co → WinError 10060 连接超时
hf-mirror.com → HTTP 200 ✅
你的脚本会卡在 0% 无限转圈，而实例在持续扣机时。
修法：export HF_ENDPOINT=https://hf-mirror.com
❌ 错误 4 · 工作流 JSON 是伪格式，ComfyUI 导不进去
你写的真实的
Wan2.2ImageToVideoWan22ImageToVideoLatent（22 无点，Latent 结尾）
CheckpointLoaderSimple + sdxl-base不是 checkpoint 结构！要用 UNETLoader + VAELoader + CLIPLoader 分开加载
缺 ModelSamplingSD3必须有，shift=8——缺它画质会崩
缺 last_node_id/size/inputs/outputs缺这些字段 ComfyUI 直接拒绝加载
已修：直接抓了官方模板原文（video_wan2_2_5B_ti2v.json，14,175 字节，HTTP 200），基于它生成 3 套可直接 Load 的工作流。
❌ 错误 5 · 默认参数会让第一条就 OOM
官方模板默认 1280×704 / 121 帧，是给 A100/H100（24GB+）准备的。T4 只有 16GB，而权重加起来 16.89GB 已超显存，必须 offload 硬撑 → 极慢甚至 OOM，失败照样扣机时。
已修：降到 480×832 / 49 帧。

② T4 的三条硬限制

T4 是 Turing 架构（SM 7.5），不是新卡。这三条决定了为什么必须降配：

限制后果应对
不支持 bf16（需 Ampere SM80+）只能用 fp16 权重✅ 已选 fp16 版主模型
不支持原生 fp8（需 Ada/Hopper）文本编码器走软件反量化，比硬件 fp8 慢可接受；嫌慢可换 umt5_xxl_fp16（11.37GB，更吃显存）
不支持 FlashAttention 2（需 Ampere+）注意力走朴素实现，显存与速度都吃亏别装 flash-attn，装了也编译不过

③ 20 机时怎么花（最关键的判断）

先纠正预期：你说的「10 秒 Wan2.2 视频约 3 分钟/条」大概率来自更强的卡。10 秒 @24fps = 240 帧，是官方默认 121 帧的近 2 倍；T4 还要吃 fp8 软解 + 无 FlashAttention + 显存 offload 三重折扣。

诚实估算区间（首次实跑后必须回填实测值，别拿估算当结论）

档位分辨率 × 帧数单条预估20 机时（16.7h T4）能出
小样480×832×49（约2s）约 4~10 分钟约 100~250 条
标准480×832×81（约3.4s）约 8~16 分钟约 60~125 条
官方默认1280×704×121约 25~60 分钟约 17~40 条
你说的档1280×704×240约 50~120 分钟仅 8~20 条
结论：20 机时够跑完整部漫剧的分镜小样（60~120 个镜头），前提是走小样/标准档，不是 10 秒满帧档。

额度优先级（按你的安排执行）

额度数量到期用法
绑定赠送（长期）20 机时2027-09-16✅ 优先用这个
每日签到（短期）2 机时剩余 6 天留作应急
每日活跃+2 机时/天短期顺手

截图确认：当前 已用 0/22 机时（0%），干净启动。

三条省钱铁律

  1. 跑第一条就掐表 —— 手机秒表记一次，回填预估值再决定批量规模。别凭估算一把梭。
  2. 模型只下一次 —— 16.89GB 下完，重启实例不重下（脚本有跳过逻辑）。但删了实例就要重下。
  3. 跑完立刻停机 —— 官方明确：资源包耗尽不会自动停机，会转按量付费扣余额；IDE 页面挂着（哪怕最小化）照样扣。

④ 一键部署脚本（全选复制 → 粘进 Cloud Studio 终端 → 回车）

已落盘 docs/CloudStudio_T4_Wan2.2_一键部署.sh 7 处修正 

#!/bin/bash
# Cloud Studio T4 · ComfyUI + Wan2.2 TI2V-5B 漫剧零成本部署
# v1.0 · 2026-09-16 · 汤小龙（AI 分身）
set -o pipefail
WORKDIR="$HOME"; COMFY="$WORKDIR/ComfyUI"

echo "=========== [0/6] 环境准备 ==========="
# 国内网络关键：HF 直连不通，必须走镜像
export HF_ENDPOINT="https://hf-mirror.com"
export HF_HUB_ENABLE_HF_TRANSFER=1
export PIP_INDEX_URL="https://mirrors.aliyun.com/pypi/simple"
export PIP_TRUSTED_HOST="mirrors.aliyun.com"
python -V; echo "HF_ENDPOINT=$HF_ENDPOINT"; df -h "$WORKDIR" | tail -1
echo "→ 需要至少 25GB 可用空间（模型 16.9GB + 依赖 + 输出）"

echo "=========== [1/6] 拉取 ComfyUI ==========="
cd "$WORKDIR"
if [ ! -d "$COMFY" ]; then
  git clone --depth 1 https://github.com/comfyanonymous/ComfyUI.git \
    || git clone --depth 1 https://gh-proxy.com/https://github.com/comfyanonymous/ComfyUI.git \
    || { echo "!! GitHub 不可达"; exit 1; }
fi
cd "$COMFY" || exit 1
echo "ComfyUI: $(git log -1 --format='%h %ad' --date=short)"

echo "=========== [2/6] PyTorch cu121 ==========="
# T4 是 Turing 架构，只支持 fp16
python -m pip install --upgrade pip -q
python -m pip install torch torchvision torchaudio \
  --index-url https://download.pytorch.org/whl/cu121
python -c "import torch;print('torch',torch.__version__,'| cuda=',torch.cuda.is_available(),'| cap=',torch.cuda.get_device_capability() if torch.cuda.is_available() else 'N/A')"

echo "=========== [3/6] 依赖 ==========="
python -m pip install -r requirements.txt
if [ ! -d custom_nodes/ComfyUI-VideoHelperSuite ]; then
  git clone --depth 1 https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git custom_nodes/ComfyUI-VideoHelperSuite \
    || git clone --depth 1 https://gh-proxy.com/https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git
fi
[ -f custom_nodes/ComfyUI-VideoHelperSuite/requirements.txt ] && \
  python -m pip install -r custom_nodes/ComfyUI-VideoHelperSuite/requirements.txt
python -m pip install -U "huggingface_hub[hf_transfer]"

echo "=========== [4/6] 下载 Wan2.2 模型（hf-mirror） ==========="
# 官方仓是 Comfy-Org/Wan_2.2_ComfyUI_Repackaged，不是 Wan-Video/Wan2.2-5B
python - <<'PYEOF'
import os, shutil
os.environ.setdefault("HF_ENDPOINT", "https://hf-mirror.com")
os.environ.setdefault("HF_HUB_ENABLE_HF_TRANSFER", "1")
from huggingface_hub import hf_hub_download
JOBS = [
    ("Comfy-Org/Wan_2.2_ComfyUI_Repackaged",
     "split_files/diffusion_models/wan2.2_ti2v_5B_fp16.safetensors",
     "models/diffusion_models/wan2.2_ti2v_5B_fp16.safetensors"),
    ("Comfy-Org/Wan_2.2_ComfyUI_Repackaged",
     "split_files/vae/wan2.2_vae.safetensors",
     "models/vae/wan2.2_vae.safetensors"),
    ("Comfy-Org/Wan_2.1_ComfyUI_repackaged",
     "split_files/text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors",
     "models/text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors"),
]
STAGE = "models/_stage"
for repo, src, dst in JOBS:
    if os.path.exists(dst) and os.path.getsize(dst) > 100_000_000:
        print("[SKIP]", dst); continue
    os.makedirs(os.path.dirname(dst), exist_ok=True)
    print("[GET ]", repo, "->", os.path.basename(src), flush=True)
    shutil.move(hf_hub_download(repo_id=repo, filename=src, local_dir=STAGE), dst)
    print("[ OK ]", dst, round(os.path.getsize(dst)/2**30,2), "GB", flush=True)
shutil.rmtree(STAGE, ignore_errors=True)
print("\n--- 模型落位自检 ---")
for _,_,d in JOBS:
    print(("  OK " if os.path.exists(d) else "  MISS ")+d)
PYEOF

echo "=========== [5/6] 官方模板包 ==========="
python -m pip install comfyui-workflow-templates -q 2>/dev/null \
  && echo "模板已装：界面 → 工作流 → 浏览模板 → 视频 → Wan 2.2" \
  || echo "（模板包装失败不影响，手动 Load 我们的 JSON 即可）"

echo "=========== [6/6] 启动 ==========="
echo "→ 启动后回 Cloud Studio 侧边栏点 8188 预览进入"
echo "→ ⚠️ 跑完务必【应用管理 → 停止使用】！"
python main.py --listen 0.0.0.0 --port 8188 --preview-method none
