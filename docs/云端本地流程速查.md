
## 5. 云端 ↔ 本地同步机制（同时迭代吗？）

**是"单向同步"，不是双向同时改**：

```
云端（CNB 仓库）── git push ──▶ 本地（E盘）──镜像──▶ G盘 / Obsidian
```

| 项 | 云端（CNB 仓库） | 本地（E/G盘技能库） | 迭代关系 |
|----|-----------------|--------------------|----------|
| 龙虾五步法 | `skills/lobster_five_step_v2.8/SKILL.md`（v2.8） | `E:/.../技能库/lobster_task_standard_workflow_v2.7/` | 本地为主，云端同步 |
| 全域模板 | `config/orca/` + `templates/` | `E:/.../技能库/self-skill-龙虾五步法_v2.7_R66.md` | 云端蒸馏自本地 |
| 四角色 NPC 栈 | `.cnb/settings.yml` + `.ci/*.yml` + `adapters/`（v1.7.x） | `CNB_ClaudeCode_NPC` / `CNB_HermesCodex_NPC` | **云端为源，本地镜像** |

- **云端是唯一写入源**：所有 NPC 只在云端容器里干活、提交代码，本地从不直接改代码回推。
- **本地是消费副本**：Marvis 负责拉取 → 落盘 E/G 盘 → 建 Windows 计划任务 → 归档 Obsidian。
- **版本是同一套**：云端 `VERSION.md` + 本地 `registry.json` 记录同一迭代史，靠 `export_to_github_and_mirror.sh` 做双盘同步。

## 6. 权限边界（我能操控本地吗？）

| 层 | 谁能操作 | 状态 |
|----|---------|------|
| **CNB 云端仓库**（写代码/提交 PR/评论） | Hermes ✅（"替我上班"已开启） | 无需再授权，直接干 |
| **云端→本机任务清单**（`local_job_queue.json`） | Hermes 生成清单，**Marvis 在本机消费** | 只需确认本地环境变量（Cookie/Token） |
| **Windows 本地**（E盘/G盘/Obsidian/计划任务） | ❌ 云端 NPC 碰不到，**Marvis 本机执行** 或你手动跑脚本 | 需在本机跑三个脚本（见第 4 节） |

> **这不叫"需要授权"，叫"物理边界"** —— 云端和本地之间靠 git + 脚本接力，不做远程桌面式操控。

## 8. 常见问题 FAQ

**Q1：接单能不能直接说"接单"？要 @ 哪个 NPC？**
能。直接 `@hermes 接单：<需求>`，Hermes 自动拆单派活，不用四个都 @。

**Q2：交付的成果存在哪？文件太多找不到。**
认准两处：① 云端看 `docs/云端产物交付清单.md`；② 订单成品看 `fleet_exchange/results/` 或 `01_正在执行实单/<订单名>/最终交付文件/`。

**Q3：云端龙虾五步法 / 全域模板和本地是同时迭代的吗？**
是同一套，靠版本号对齐：云端 `VERSION.md` ↔ 本地 `registry.json`。云端改工程栈 → 本地拉镜像；本地改模板 → 云端人设蒸馏同步。

**Q4：你能操控本地电脑吗？**
不能。云端 NPC 物理碰不到 Windows 本地；本地执行由 Marvis 按 `local_job_queue.json` 完成，或你本机跑脚本。

**Q5：跑一次大概花多少核时？**
镜像构建约 0.8 核时/次，NPC 调用若干轮，全部走 CNB 免费 1600 核时/月配额，**零外部付费 API**（实测 `milli_credit=0`）。
