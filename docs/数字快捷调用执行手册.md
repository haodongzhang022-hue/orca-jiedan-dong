> 版本：v1.1 | 更新：2026-08-13（1234 改名字） | 归属：龙虾五步法 §11.3 + 全域模板 #303/#304 + 项目脚手架三文件
> 用途：用户说四大武器**名字**（或快捷数字 1/2/3/4、组合如「一人一公司 接单」「3 迭代」）时，
> 本手册给出**每一步的实质执行动作**，避免"只有映射文字、没有可执行内容"的空转。本手册是三处注册点的落地执行细则。

## 触发规则（全域通用 · 名字为主，数字为快捷）

- 名字触发（主）：`一人一公司` / `马斯克×巴菲特蒸馏` / `三载体联动迭代` / `四化迭代 Obsidian` → 直接触发对应任务
- 数字快捷（别名）：`1` / `2` / `3` / `4` → 等价触发，说数字也可
- 组合触发：`一人一公司+马斯克 接单` / `1+3` / `2+4 复盘` → 按顺序依次执行各任务，共用同一轮工作区
- 附带业务：`一人一公司 接单`（先调一人一公司角色再走接单流水线）、`马斯克 报价`（用双雄思维做报价研判）
- 运维触发词（2026-08-18 新增）：`方案B` / `3081网关` / `Failed to fetch` / `获取可用模型` → 打开 `docs/方案B_本机3081网关启动路径详解_20260818.md`，按详细路径照抄执行（启动本机3081网关 → curl验证JSON → 回Harness创建提供方）
- Harness 配置触发词（2026-08-18 新增）：`DeepSeek Harness 配置` / `怎么填` / `Provider 字段` / `配置映射` / `创建提供方` / `添加模型` → 打开 `docs/DeepSeekHarness_Provider配置界面字段一一对应映射表_20260818.md`，照映射表逐字段填（直连CNB `.../-/ai` 或本机3081 `http://127.0.0.1:3081/v1`，模型必须 `deepseek-v4-flash`）
- 铁律：按四化自主执行，不反复询问；每项完成后写清产出路径

## 1 · 一人一公司（agency-agents）

**资源**：`E:\龙虾AI主控中心\我的AI分身\技能库\agency-agents\`（17 部门 200+ 角色，MIT 开源）

**实质执行步骤**：
1. 按任务类型选角色：设计单 → `design/` 8 角色（ui-designer / brand-guardian / visual-storyteller）；营销 → `marketing/` 30 角色（含中国本地化+一人公司优化）；工程 → `engineering/` 29 角色；其余查 `integrations/antigravity/` 184 个 SKILL.md
2. 加载角色身份卡（身份/流程/交付物/验收标准），把角色要求注入执行 Agent 提示词
3. 产出：角色套用的任务执行结果（设计稿/文案/代码/方案）
4. 验收：按角色验收标准 + @CLAUDE CODE review_report
5. 归档：案例回灌 `docs/技能沉淀/` + Obsidian 对应库

**产出路径**：`01_正在执行实单/【任务】/` 或 `02_候选设计稿/`

**产出路径**：任务卡目录或 `docs/技能沉淀/`
