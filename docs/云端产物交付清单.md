## 二、Marvis 本机部署执行清单（按 local_job_queue.json 消费）

> 云端只产出源码与结构化任务清单；**Windows 计划任务创建、E/G 盘落盘、Obsidian 录入由 Marvis 在本地执行**。

### 1. 拉取仓库文件
```bash
# 在本地工作目录拉取 PR #21 源分支
git fetch origin auto/autogpt-orca-1ef5
git checkout auto/autogpt-orca-1ef5
```

### 2. 触发器校验 + 任务清单确认（云端已生成 local_job_queue.json）
```bash
python scripts/auto_gpt_trigger_config.py validate   # 校验触发器配置
python scripts/auto_gpt_trigger_config.py list       # 查看触发器摘要
python scripts/auto_gpt_trigger_config.py export     # 重新生成 local_job_queue.json（可选）
```

### 3. 按任务清单在本机落 Windows 计划任务（Marvis 负责，不在此生成命令）
| 任务名 (task_name) | 脚本 (file_path) | 参数 (params) | 调度 |
|--------------------|------------------|---------------|------|
| `xianyu_daily_post` | `scripts/auto_xianyu_scheduler.py` | `--action post` | 每日 09:00 |
| `credential_daily_check` | `scripts/auto_gpt_orca_bridge.py` | `trigger --workflow 通用 --action credential_check` | 每日 00:00 |
| `quant_dual_check` | `scripts/quant_scheduler.py` | `--action dual_check` | 每 30 分钟 |
| `xianyu_crawler_poll` | `scripts/auto_xianyu_scheduler.py` | `--action crawler_poll` | 每 10 分钟 |

> 调度参数统一取自 `config/autogpt/triggers.yaml` 与 `local_job_queue.json`，Marvis 据此创建计划任务即可。

### 4. 本地业务前置条件
- **闲鱼**：配置 `XIANYU_COOKIE` 环境变量（或复用 DPAPI Cookie 解密体系）；草稿队列 `config/autogpt/xianyu_draft_queue.json`、待回复消息目录 `logs/xianyu/inbox/`、统计源 `logs/xianyu/stats_raw.json`
- **量化**：配置 `BINANCE_API_KEY/SECRET`、`JIASHENG_TOKEN/ACCOUNT`；三端数据源 `logs/quant/market_side.json / account_side.json / record_side.json`
- **凭证**：`CNB_TOKEN`/`GH_TOKEN`/抖音/小红书 Cookie 从环境变量注入（云端仅校验存在性）

### 5. E/G 双盘 + Obsidian 归档
```bash
bash scripts/export_to_github_and_mirror.sh    # E/G 双盘 + Obsidian + CNB 五大仓库同步
```
