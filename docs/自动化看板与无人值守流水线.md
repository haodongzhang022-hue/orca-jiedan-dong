# 自动化看板与无人值守流水线

> 目标：把「Hermes → Codex → CloudCode → 交付」做成 WorkBuddy 自动中转，用户只下命令、看板监督、最终交付物自动落盘到 `企业微信群/定制接单项目/deliverables/`，复制到企业微信群即可。

---

## 一、核心组件

| 组件 | 路径 | 职责 |
|---|---|---|
| 项目本地总线 | `企业微信群定制接单项目/fleet_exchange/` | 任务 incoming / doing / results / logs 全在项目内，避免沙箱权限问题 |
| 看板 HTML | `企业微信群/定制接单项目/任务看板/index.html` | 实时显示流水线状态，15 秒自动刷新 |
| 看板数据 | `任务看板/dashboard_data.json` | 由 autopilot 每 30 秒生成 |
| 自动驾驶 | `scripts/pipeline_autopilot.py` | 扫描本地总线，自动写下一层任务 |
| 看板守护 | `scripts/pipeline_autopilot_daemon.py` | 每 30 秒循环调用 autopilot |
| 本地拉取脚本 | `scripts/fleet_pull.sh` | Agent 从项目本地总线拉取任务（支持文件名 `_Hermes_` 或 frontmatter `to: Hermes`） |
| 本地回写脚本 | `scripts/fleet_done.sh` | Agent 完成任务后回写 results/ 并归档到 done/ |
| 交付物目录 | `企业微信群/定制接单项目/deliverables/` | 最终结果落盘，用户复制到企业微信群 |

## 三、无人值守流程

```
用户把任务卡放入项目本地 fleet_exchange/incoming/（或 WorkBuddy 直接写）
              ↓
Hermes 自动拉取（scripts/fleet_pull.sh） → 产出 design_brief → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 自动写 Codex 任务到 incoming/
              ↓
Codex 自动拉取 → 产出方案 → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 自动写 CloudCode 任务到 incoming/
              ↓
CloudCode 自动拉取 → 终审 → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 汇总交付物 → 复制到 企业微信群/定制接单项目/deliverables/<task_id>/
```

**Agent 自动拉取模式**：在 ORCA 三工作树终端分别运行一次即可挂机。

```bash
bash "E:/龙虾AI主控中心/我的AI分身/企业微信群定制接单项目/scripts/fleet_pull.sh" auto 30 600
```

含义：每 30 秒扫描一次，连续 10 分钟无任务自动退出。

如果 `fleet_pull.sh` 无法识别 Agent，手动指定：

```bash
bash scripts/fleet_pull.sh auto 30 600 Hermes
bash scripts/fleet_pull.sh auto 30 600 Codex
bash scripts/fleet_pull.sh auto 30 600 CloudCode
```

## 五、故障排查

| 现象 | 检查 |
|---|---|
| 看板打不开 | 是否已启动 `python -m http.server 8000` |
| 看板数据不更新 | 守护进程 `pipeline_autopilot_daemon.py` 是否运行 |
| Agent 不拉任务 | 任务卡 frontmatter 是否含 `to: Hermes/Codex/CloudCode` |
| 任务卡被沙箱拒绝改名 | 不用改名，本地 `fleet_pull.sh` 已支持 frontmatter 匹配 |
| 交付物目录为空 | 确认 CloudCode 已完成并把结果写回 `fleet_exchange/results/` |
| 想发到企业微信群 | 当前无企业微信 connector，从 `deliverables/` 复制图片/文案到企业微信群即可 |
