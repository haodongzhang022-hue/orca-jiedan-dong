# 自动化看板与无人值守流水线

> 目标：把「Hermes → Codex → CloudCode → 交付」做成 WorkBuddy 自动中转，用户只下命令、看板监督、最终交付物复制到企业微信群。

---

## 一、核心组件

| 组件 | 路径 | 职责 |
|---|---|---|
| 看板 HTML | `E:/龙虾AI主控中心/我的AI分身/企业微信群/定制接单项目/任务看板/index.html` | 实时显示流水线状态，15 秒自动刷新 |
| 看板数据 | `任务看板/dashboard_data.json` | 由 autopilot 每 30 秒生成 |
| 自动驾驶 | `scripts/pipeline_autopilot.py` | 扫描各 Agent 产出，自动写下一层任务 |
| 看板守护 | `scripts/pipeline_autopilot_daemon.py` | 每 30 秒循环调用 autopilot |
| 同步兜底 | `scripts/sync_to_fleet.sh` | 沙箱无法写 `fleet_exchange/incoming/` 时，手动同步待分发任务 |
| 交付物目录 | `E:/龙虾AI主控中心/我的AI分身/企业微信群/定制接单项目/deliverables/` | 最终结果落盘，用户复制到企业微信群 |

## 二、访问看板

浏览器打开：

```
http://localhost:8000
```

如果服务未启动，在终端运行：

```bash
cd "E:/龙虾AI主控中心/我的AI分身/企业微信群/定制接单项目/任务看板"
python -m http.server 8000
```

## 三、无人值守流程

```
用户下令 → WorkBuddy 写任务卡到 fleet_exchange/incoming/
              ↓
Hermes 自动拉取 → 产出 design_brief → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 自动写 Codex 任务到 incoming/
              ↓
Codex 自动拉取 → 产出海报方案 → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 自动写 CloudCode 任务到 incoming/
              ↓
CloudCode 自动拉取 → 终审 → 写回 results/
              ↓ (WorkBuddy autopilot 检测)
WorkBuddy 汇总交付物 → 复制到 企业微信群/定制接单项目/deliverables/
```

**Agent 自动拉取模式**：在 ORCA 三工作树终端分别运行一次即可挂机。

```bash
bash "E:/龙虾AI主控中心/我的AI分身/多智能体舰队编排/fleet_exchange/fleet_pull.sh" auto 30 600
```

含义：每 30 秒扫描一次，连续 10 分钟无任务自动退出。

## 四、沙箱权限兜底

`scripts/pipeline_autopilot.py` 会优先尝试直接写 `fleet_exchange/incoming/`。  
若沙箱/权限拦截，则自动把任务写到项目 `待分发任务/` 目录，看板会显示**黄色警告**和**「同步待分发任务」按钮**。  
此时在项目根目录运行：

```bash
bash scripts/sync_to_fleet.sh
```

即可把任务推到真正的舰队总线。

## 五、首单 PILOT-001 特殊处理

当前 PILOT-001 任务卡文件名：

```
20260725_014500_0__PILOT_企业微信群定制海报_摇滚风宣传海报.md
```

缺少 `_Hermes_` 标记，`fleet_pull.sh` 自动轮询不会拉取。  
两种启动方式：

1. **Hermes 手动读**（推荐首单）：
   ```bash
   cat "E:/龙虾AI主控中心/我的AI分身/多智能体舰队编排/fleet_exchange/incoming/20260725_014500_0__PILOT_企业微信群定制海报_摇滚风宣传海报.md"
   ```
2. **自动轮询模式**：把文件名改为含 `_Hermes_` 前缀。本机运行一次：
   ```bash
   cd "E:/龙虾AI主控中心/我的AI分身/多智能体舰队编排/fleet_exchange/incoming"
   mv "20260725_014500_0__PILOT_企业微信群定制海报_摇滚风宣传海报.md" \
      "20260725_014500_0__Hermes_PILOT_企业微信群定制海报_摇滚风宣传海报.md"
   ```

## 六、故障排查

| 现象 | 检查 |
|---|---|
| 看板打不开 | 是否已启动 `python -m http.server 8000` |
| 看板数据不更新 | 守护进程 `pipeline_autopilot_daemon.py` 是否运行 |
| Agent 不拉任务 | 任务卡文件名是否含 `_Hermes_` / `_Codex_` / `_CloudCode_` |
| 看板提示待同步 | 运行 `bash scripts/sync_to_fleet.sh` |
| 交付物目录为空 | 确认 CloudCode 已完成并把结果写回 `fleet_exchange/results/` |
