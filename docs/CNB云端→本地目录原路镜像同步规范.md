# 《CNB云端 → 本地目录原路镜像同步规范》

> 归属：orca-jiedan 舰队 · Hermes（大脑层·全域模板调度）
> 版本：v1.0 | 日期：2026-08-18
> 触发词：`云端本地原路同步` / `原路同步` / `镜像同步`
> 目标：把 CNB 云端仓库产出文件**原路回写**到本地对应项目目录，杜绝"统一丢 D 盘新建文件夹"导致的文件散落找不到问题。

---

## 一、一句话结论

> **CNB 云端仓库里的目录结构是什么样，本地 `E:\龙虾AI主控中心\我的AI分身\` 下面就连同项目文件夹复刻一模一样的目录树；云端某个项目产生的脚本 / Python / 配置 / 子文件夹，下载同步时按仓库相对路径镜像落到本地对应项目内部，绝不统一丢 D 盘新建文件夹。**

---

## 二、根基准本地路径（固定不变）

```
E:\龙虾AI主控中心\我的AI分身\
```

所有云端项目（闲鱼 / 量化EA / 企业接单群 / 网盘 / 课程等）全部遵循本规范，统一挂在这个根基准下，且**云端项目文件夹 ↔ 本地项目文件夹一一对应**。

| 云端项目（仓库内） | 本地落地根（E盘） |
|---|---|
| `企业微信群定制接单项目/`（本仓库 orca-jiedan） | `E:\龙虾AI主控中心\我的AI分身\企业微信群定制接单项目\` |
| 量化项目 | `E:\龙虾AI主控中心\我的AI分身\量化...\` |
| 闲鱼项目 | `E:\龙虾AI主控中心\我的AI分身\闲鱼...\` |
| 网盘 / 课程项目 | 以此类推，云端建什么子文件夹，本地同位置生成一模一样 |

> **⚠️ 本地已存在完整项目树，直接复用现有文件夹，不要新建 D 盘隔离目录。**

---

## 三、原路回写规则（核心）

1. **云端目录结构 = 本地目录结构**：云端仓库内某个项目产生的脚本、Python、配置、子文件夹，同步到本地时**按仓库相对路径镜像落地**，不改变相对位置。
2. **同一项目产出必须进同一项目文件夹**：云端 `企业微信群定制接单项目` 的所有产出，一律落本地 `E:\龙虾AI主控中心\我的AI分身\企业微信群定制接单项目\`；云端生成了什么子文件夹，本地同路径下就生成一模一样的子文件夹，脚本、bat、py 全部放对应本地项目目录内部。
3. **量化 / 闲鱼 / 课程项目以此类推**：云端项目目录结构什么样，本地 `E:\龙虾AI主控中心\我的AI分身\` 下面就复刻一模一样目录树，文件原路返回对应位置。
4. **严禁**：**禁止把云端文件统一输出到 D 盘根目录新建文件夹**；禁止跨项目把文件混放到无关目录。

## 四、网关脚本专属落地位置（gateway_service）

网关相关脚本（`gateway_3080.py` / `start_gateway_3080.bat`）**固定**落地到：

```
E:\龙虾AI主控中心\我的AI分身\企业微信群定制接单项目\scripts\gateway_service\
```

- ✅ 仓库相对路径：`scripts/gateway_service/`
- ✅ 本地镜像路径：`E:\龙虾AI主控中心\我的AI分身\企业微信群定制接单项目\scripts\gateway_service\`
- ❌ **不再使用 `D:\dsh-gateway` 等 D 盘路径**，全部归入现有 E 盘项目树，统一管理查找。

## 五、工作流程（镜像落地 → 启动网关 → 配置 Harness）

```
Step1  云端生成/更新脚本资源
   ↓
Step2  按云端仓库相对路径，镜像落地到本地 E 盘对应项目文件夹
   ↓
Step3  在本地该目录双击 bat 一键启动网关
       E:\...\企业微信群定制接单项目\scripts\gateway_service\start_gateway_3080.bat
   ↓
Step4  网关启动完成后，去 DeepSeek-Harness 界面配置网关 Provider
       base_url = http://127.0.0.1:3081
       model    = deepseek-v4-flash（免费）
```

**操作要点**：
- 双击 `start_gateway_3080.bat` → 自动在 `scripts\gateway_service\` 同目录找 `gateway_3080.py` 启动，监听 `127.0.0.1:3081`。
- 网关起来后 `curl http://127.0.0.1:3081/health` 必须返回 JSON。
- 再去 Harness「创建提供方」界面配置，字段映射详见 `docs/DeepSeekHarness_Provider配置界面字段一一对应映射表_20260818.md`。

## 六、安全约束（零明文）

- 密钥一律走环境变量 `CNB_TOKEN` 注入，**严禁明文写进本地任何脚本文件**。
- `start_gateway_3080.bat` 优先读 `CNB_TOKEN` 环境变量；若本地有 `.cnb_token` 便利文件也仅本地使用、不随仓库提交；无则引导手动输入（仅当前会话有效，不落盘）。
- 配置文件 / 仓库内禁止出现任何 Token / Key 明文。
