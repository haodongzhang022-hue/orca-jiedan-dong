# 本机 3081 网关 · 本地盘符落地可视化指南（Windows）

> **给汤嘉锋的一句话**：之前你一直找不到文件，是因为我一直在讲**云端路径**和**仓库相对路径**（如 `deploy/dsh-desktop/gateway_3080.py`）。但那是**仓库里的路径**，不是**你电脑硬盘上的路径**。这份指南给你**确定到盘符的本地落地位置**，照着做即可。

---

## 〇、先说清楚：你电脑上的文件从哪来

`gateway_3080.py` 目前**只存在于云端仓库**（https://cnb.cool/TJF19770107/orca-jiedan），
**你本地电脑上还没有这个文件**，所以你在硬盘里搜 `gateway_3080.py` 当然找不到。

要让文件出现在你本地，只有一条路：**把它从仓库下载/同步到你电脑**（下面①-③ 任选其一）。

---

## 一、给你定一个"固定落地点"：`D:\dsh-gateway\`

以后**所有东西都放这一个文件夹**，别再到处找，别再放别处。就两个文件：

```
D:\dsh-gateway\
├── gateway_3080.py              ← 网关本体（核心文件）
└── start_gateway_3080.bat       ← 启动脚本（双击这个就能跑）
```

---

## 二、怎么把两个文件弄到 `D:\dsh-gateway\`（三选一）

### 方式① 网页直接下载（最快，推荐给不会命令行的人）
1. 浏览器打开：https://cnb.cool/TJF19770107/orca-jiedan
2. 点进入 `deploy/dsh-desktop/` 文件夹
3. 点开 `gateway_3080.py` → 右上角「下载」
4. 进入 `scripts/` 文件夹 → 点开 `start_gateway_3080.bat` → 右上角「下载」
5. 在电脑上新建文件夹 `D:\dsh-gateway`（在"D盘"空白处右键 → 新建 → 文件夹 → 命名 `dsh-gateway`）
6. 把下载的 2 个文件**移动/复制**进去

### 方式② git 同步整个仓库（推荐，之后能更新）
1. 电脑上装好 Git（没有就去 git-scm.com 装）
2. 打开 PowerShell，执行：
```powershell
cd D:\
git clone https://cnb.cool/TJF19770107/orca-jiedan.git dsh-gateway
```
3. 完成后文件就在：
```
D:\dsh-gateway\deploy\dsh-desktop\gateway_3080.py
D:\dsh-gateway\scripts\start_gateway_3080.bat
```
> ⚠️ 用这种方式，**启动脚本在 `scripts\` 里，不是 `D:\dsh-gateway\` 根目录**。请按方式③把它们放一起，省心。

### 方式③ 放一起（最省心，推荐）
把 `gateway_3080.py` 和 `start_gateway_3080.bat` **复制到同一个文件夹**：
```powershell
# 假设你 git clone 到了 D:\dsh-gateway
copy D:\dsh-gateway\deploy\dsh-desktop\gateway_3080.py  D:\dsh-gateway\gateway_3080.py
copy D:\dsh-gateway\scripts\start_gateway_3080.bat      D:\dsh-gateway\start_gateway_3080.bat
```

---

## 三、在哪启动？双击启动脚本（不用敲命令）

1. 打开 `D:\dsh-gateway\` 文件夹
2. **双击 `start_gateway_3080.bat`**
3. 会弹出黑色窗口，自动：找文件 → 检测 Python → 读密钥 → 启动 3081 → 健康检查

启动成功后黑窗口显示：
```
✅ /health  → {"ok":true,...}（监听 127.0.0.1:3081）
```

> **重要**：这个黑窗口**不要关**，关了网关就停了。

---

## 四、回答你的问题"是在这个窗口输入吗？"

**你截图里那个窗口（管理员: Windows PowerShell）是用来跑命令的"命令窗口"。**

它有两个用途，别搞混：

| 你在做什么 | 该用哪个窗口 | 输入什么 |
|-----------|-------------|---------|
| **验证网关通不通** | 就是你截图的 PowerShell 窗口 | `curl http://127.0.0.1:3081/health` |
| **正式用模型对话** | 浏览器打开 DeepSeek-Harness（`127.0.0.1:3080`）| 在网页里选 `cnb-gateway-local` 提供方 |

所以：
- **网关的启动** → 双击 `start_gateway_3080.bat`（黑窗口），**不是**在 PowerShell 里敲
- **验证网关** → 在你截图的 PowerShell 窗口敲 `curl http://127.0.0.1:3081/health`
- **真正用模型** → 在 Harness 网页（3080）里用

> ⚠️ 注意端口：`3081` 才是网关，`3080` 是 Harness 网页。你之前 curl `3080` 返回 HTML 网页是**正常的**（那是 Harness 网页本身），网关要 curl **3081**。

## 五、端口速查

| 端口 | 是什么 | 访问它返回 | 用什么 |
|------|--------|-----------|--------|
| **3080** | DeepSeek-Harness WebUI（网页后台） | HTML 网页 | 浏览器打开做配置/对话 |
| **3081** | 你的 3081 网关（gateway_3080.py） | JSON | curl 验证 / 工具填 base_url |

## 七、如果哪个文件找不到 / 没反应

| 现象 | 原因 | 解决 |
|------|------|------|
| 双击 bat 提示"找不到 gateway_3080.py" | 两个文件没放同一目录 | 按方式③放一起 |
| 提示"没有 Python" | 电脑没装 Python | 到 python.org 装 Python 3.11，勾选 Add to PATH |
| curl 3081 报"无法连接" | 网关没启动 | 重新双击 bat，别关黑窗口 |
| curl 3080 返回网页 | 正常！3080 是 Harness 网页 | 网关用 3081，不是 3080 |
| 对话报 Failed to fetch | 网关没起或地址填错 | 确认网关起了，API 地址填 `http://127.0.0.1:3081/v1` |
