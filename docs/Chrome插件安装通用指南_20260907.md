## 一、先纠正一个误解：装插件 ≠ 下载压缩包

| 你以为的 | 实际的 |
|---|---|
| 先下载一个 zip 压缩包 → 复制粘贴进浏览器插件栏 | ❌ 插件栏**不能粘贴文件夹** |
| 必须手写扩展 ID | ❌ ID 是 Chrome **自动生成**的，人不用写 |
| 「加载已解压」需要 zip | ❌ 需要的是**已解压的文件夹**（里面必须有 `manifest.json`） |

**正确认知**：
- **在线装**（首选）：能访问 Chrome 商店时，直接点「添加至 Chrome」，一分钟搞定，不需要任何压缩包。
- **离线装**（商店进不去/内网/特殊浏览器）：手上要有 zip 或 crx → **先解压成文件夹** → 走「开发者模式 → 加载已解压」。
- zip 里的东西解压出来后，**双击 manifest.json 是没用的**，必须通过开发者页面选文件夹。

## 二、三条安装路线（按优先级）

### 路线 A：商店在线装（首选，最简单）
1. 浏览器打开 Chrome 网上应用店：`https://chromewebstore.google.com/`
2. 搜索插件名（如 Obsidian Web Clipper）
3. 点「添加至 Chrome」→ 确认 → 完成
- 特点：自动更新、不用管 ID、不用解压。

### 路线 B：开发者模式 · 加载已解压（离线标准法，人手动推荐）⭐
1. **拿到插件文件夹**：
   - 有 zip → 右键解压到一个**固定不移动的目录**（如 `D:\ChromeExt\插件名\`）
   - 有 crx → 改后缀为 zip 再解压（部分 crx 需专用工具）
   - 注意：解压后的文件夹里必须能直接看到 `manifest.json`（不是多套一层文件夹）
2. 浏览器地址栏输入：`chrome://extensions/`
3. 打开右上角「**开发者模式**」开关
4. 点左上角「**加载已解压的扩展程序**」→ 选中第 1 步的**文件夹**（选中文件夹本身，不进入里面）→ 确定
5. 工具栏拼图图标里把插件「📌固定」出来即可用

**关键规则**：
- 扩展 ID 由**文件夹路径哈希**自动生成 → **文件夹移动/改名/删除 = 插件失效**，需重新加载
- 装好后文件夹**永久保留**，不能当临时文件删
- Edge 路径：`edge://extensions/`（同样有开发者模式+加载解压）；360 浏览器同理

### 路线 C：配置文件注册（AI 自动化路线 / 救急法，人不推荐）
> 本次汤小龙实际用的方法——因为 GptBrowser 的「加载已解压」系统弹窗自动化点击不稳定。

1. 找到浏览器**真·数据目录**（见第三节对照表）
2. 关闭浏览器主进程
3. 编辑 `数据目录\Default\Secure Preferences`（JSON），在 `extensions.settings` 下新增：
```json
"<扩展ID>": {
  "location": 4,
  "path": "E:\\lobster_ai_temp_fleet\\obsidian_web_clipper"
}
```
- `location:4` = 已解压扩展；`path` = 解压文件夹绝对路径（JSON 里反斜杠要双写 `\\`）
4. 重启浏览器 → 插件出现
- 风险：改坏 JSON = profile 损坏，改前**必须备份**该文件
- 人的手动场景**用不到这条**，路线 B 完全够

## 三、本机三个浏览器的数据目录对照表（实测）

| 浏览器 | 进程 | 数据目录（Default） | 扩展清单文件 |
|---|---|---|---|
| #1 带AI 谷歌（GPT浏览器） | `GptBrowser.exe` | `C:\Users\Administrator\AppData\Local\SPChrome\User Data\Default` | 同目录 `Secure Preferences`（31个扩展） |
| #2 本地普通谷歌 | `chrome.exe --user-data-dir=...\LocalProfile` | `C:\Users\Administrator\AppData\Local\Google\Chrome\LocalProfile\Default` | 同目录 `Secure Preferences` |
| 香港代理谷歌（不带AI） | `chrome.exe --proxy-server=socks5://127.0.0.1:1081 --user-data-dir=...\ProxyProfile` | `C:\Users\Administrator\AppData\Local\Google\Chrome\ProxyProfile\Default` | 同目录 `Secure Preferences`（13个扩展，含商店版OCD 1.7.1） |

**怎么查证某个浏览器的真数据目录（不靠猜）**：
1. 任务管理器看进程，或用脚本枚举进程命令行（ctypes `NtQueryInformationProcess`）
2. 命令行里的 `--user-data-dir=...` 就是答案
3. 兜底：找该浏览器配套 `crashpad-handler.exe` 进程的 `--user-data-dir`，主进程没写时它一定写

> ⚠️ 本次最大坑：#1 AI 浏览器数据目录**不是** `D:\Chrome\UserData`（那是#2的），而是 **SPChrome**。读错目录 → 怎么改都"装不上"。

## 四、本次踩坑全记录（错误 → 解决）

| # | 错误/坑 | 根因 | 解决 |
|---|---|---|---|
| 1 | 读 `D:\Chrome\UserData` 找不到 chrome-mcp-server、OCD | #1 AI 浏览器真目录是 SPChrome，不是 D:\Chrome | 进程命令行枚举定位真目录 |
| 2 | "装了俩"（两条 OCD 都指向同一目录） | 两次写入注册项，id 不同路径相同 | 无害，保留不动（loc=4 两条） |
| 3 | 给窗口截图是空白的 | GPU 硬件加速窗口 `PrintWindow` 返回空 | 改用**屏幕 BitBlt**：SetForegroundWindow + ShowWindow(9/3) 置顶最大化后抓桌面DC |
| 4 | 地址栏导航点坐标 (700,40) 不生效 | 坐标偏移 | 改用快捷键 **Ctrl+L** 聚焦地址栏再输入 |
| 5 | chrome-mcp-server 扩展红"错误" | 原生宿主 `com.chromemcp.nativehost` 注册正确，但指向的 `npm\node_modules\mcp-chrome-bridge\dist\run_host.bat` **缺失** | `npm i -g mcp-chrome-bridge` 补回即可（二进制缺失 → service worker 起不来） |
| 6 | GptBrowser「加载已解压」弹窗自动化点击不稳 | 系统 OpenFile 弹窗不受 UIA 控制 | 走路线 C 配置文件注册 |
| 7 | pythonw 拉起带 print 的脚本 exit 1（假成功） | sys.stdout=None | 用 python.exe（历史坑，截图脚本注意） |

**插件来源如实说明**：解压版文件夹 `E:\lobster_ai_temp_fleet\obsidian_web_clipper` 为官方 **Obsidian Web Clipper 1.7.1**（7月22日落盘，#2浏览器安装时复用至今），与香港代理浏览器商店版 **1.7.1 完全同版本**；本次会话未重新下载、未从其他浏览器复制。

## 五、常见报错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 「加载已解压」后提示缺少 manifest.json | 选到了上层的父文件夹 | 选中**直接含 manifest.json 的那层**文件夹 |
| 插件突然消失/变灰 | 文件夹被移动/删除/改名 | 放回原路径，或重新加载 |
| Service Worker 显示「无效」 | 背景脚本崩了（常因 native host 缺失 / 权限） | 见坑#5；查该插件是否需要配套本机程序 |
| 商店装不上（企业策略禁用） | 组策略限制 | 走路线 B |
| 装完图标不显示 | 未固定 | 工具栏拼图 → 该插件 → 📌 |
