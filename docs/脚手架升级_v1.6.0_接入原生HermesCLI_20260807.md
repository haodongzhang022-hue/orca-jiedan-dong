- ❌ npm 上的 `@hermesai/cli`（404 不存在）、`hermes-cli 1.0.0`（巴西旅行社搜索工具）、

  `hermes-agent`，安装后命令行即 `hermes`），定位即「编排/调度/战略大脑」，与本仓库
  `hermes/` 目录「大脑层 · 战略调度」完全同构。
