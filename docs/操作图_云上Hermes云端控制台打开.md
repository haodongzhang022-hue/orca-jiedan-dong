## ⚠️ 为什么之前打不开（1 句话）

你访问的 `on8guoflgv-6060.cnb.run` 是**修复前（旧提交 c132f1b）**启动的**旧工作区**，里面**没有装 Hermes Web UI**，所以 6060 端口一直 `connection refused`。
**这不是代码 bug**，是「旧工作区」需要删除重建。修复代码已在 main 就绪。

## 🗺️ 4 步总览（照着图点就行）

```
① 删除旧工作区 on8guoflgv
        ↓
② 回仓库 → 切 main → 点「云原生开发」（重建）
        ↓
③ WebIDE → PORTS 面板 → 添加 6060 端口
        ↓
④ 复制平台生成的真实地址 → 浏览器打开 → 看到 Hermes 控制台
```

## ① 删除旧工作区（关键！不删会复用旧环境）

个人主页 → 云原生开发环境列表 → 找到 **running 的 `on8guoflgv`**（流水线 `cnb-lb8…`）：

- 状态显示 `running（旧）`
- **务必先【关闭】再【删除】**
- 删掉后列表里不再有 `on8guoflgv` 才算成功

> ⚠️ 这步必须做——如果只点「云原生开发」不删旧工作区，平台可能直接复用旧的 `on8guoflgv`，还是打不开。

---

## ② 回仓库 → 切 main → 点「云原生开发」

1. 打开仓库 `https://cnb.cool/TJF19770107/orca-jiedan`
2. 分支切到 **`main`**（修复版 `9687302`，含 PR #38 修复）
3. 点 **「云原生开发」** 按钮 → 开始重建

这次基于最新 main，走修复后 `.cnb.yml`：

- `.ide/Dockerfile` 拉取 Hermes Web UI 镜像 `v0.6.39`
- `start.sh` 自动拉起适配层(`127.0.0.1:8787`) + Web UI(`0.0.0.0:6060`)
- stages：`verify-hermes-webui` → `start-cnb-gateway-adapter` → `start-hermes-webui`

⏳ 等镜像构建（约 1.5GB，第一次较久属正常）。

---

## ③ WebIDE → PORTS 面板 → 添加 6060 端口

构建完成后自动进入 **WebIDE 浏览器窗口**（VS Code 风格网页编辑器）：

1. 在底部（或右侧）找到 **「PORTS / 端口」** 面板
2. 点 **「添加端口 / Add Port」**
3. 填入 **`6060`** 回车

---

## ④ 复制平台生成的真实地址 → 浏览器打开 → 看到 Hermes 控制台

PORTS 面板会生成一行真实地址，例如：

```
https://fjisdofi21-6060.cnb.run
```

- **不要手打**，直接点面板里那行地址，或点「在浏览器打开 / Open in Browser」
- 那串 `fjisdofi21` 是平台自动分配的真实 id，每次启动可能不同
- 浏览器打开后出现 **Hermes Studio Web 控制台** 即成功

## 🛠️ 如果你看到这两个画面（最新踩坑：2026-08-12 实测反馈）

### 情况A：打开出现「您似乎迷失在了代码的海洋里」+ 地址栏是 `cnb.cool/undefined/-/workspace/err...`

**这是什么**：这是 **CNB 自己的「工作区不存在」报错页**，不是 Hermes 控制台。`undefined` = 你的云端工作区**已被回收/已失效**（平台回收机制：10 分钟无操作 / 最长 18 小时 / 每天凌晨 4-6 点强制回收），或者你点开了一个**旧的/失效的工作区链接**。

**怎么做（不用改代码，代码已是修复版）**：
```
1. 关闭这个报错页，回到仓库主页 https://cnb.cool/TJF19770107/orca-jiedan
2. 分支下拉框确认选 main（修复版，含 PR #38）
3. 重新点顶部「云原生开发」按钮 → 等它重建出【新的】工作区
4. 进入新的 WebIDE 后 → 底部 PORTS 面板 → 添加 6060 → 点生成的真实地址
```
> ⚠️ 每次工作区被回收后，地址里的那串随机 id 都会变，**别存旧书签**，每次从仓库「云原生开发」按钮重新进。

### 情况B：把 `curl http://127.0.0.1:8787/health` 输到了百度搜索框

**这是什么**：`curl` 是**终端命令**，不是网页搜索词。要跑它，必须在你那个 **WebIDE 的「终端/Terminal」面板**里输入，不能粘贴到百度/浏览器地址栏。

**在哪输入（WebIDE 打开后）**：
```
WebIDE 界面最底部 → 点「终端 / Terminal」标签页
（如果没看到，用顶部菜单：Terminal → New Terminal，或按快捷键 Ctrl+`）
在弹出的终端里粘贴：  curl http://127.0.0.1:8787/health
按回车 → 返回 {"model":"deepseek-v4-flash",...}  = 免费网关适配层在跑 ✅
```
> 💡 终端粘贴用 `Ctrl+Shift+V`；敲中文如果打不出来，就先把中文复制好，到终端 `Ctrl+Shift+V` 粘贴。
