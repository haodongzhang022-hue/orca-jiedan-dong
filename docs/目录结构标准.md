## 三、核心规则（强制执行）

### 1. 区分两条线：模拟单 VS 真实付费单
- 群里几十元低价需求 → 归入 `00_模拟演练案例库`，仅用来跑通流水线、沉淀技能，**不接真实交易、不对外交付**。
- 满足 ¥300 起步标准、收完定金 → 创建独立文件夹放入 `01_正在执行实单`。

> 自动判定（`scripts/business_folders.py`）：
> - `simulation: true` **或** `real_order_min < 300` → 模拟
> - `real_order_min >= 300`（且非 simulation）→ 真实付费单

### 2. 每个独立需求，单独新建带日期命名文件夹
- 命名标准：`【年月日_需求简述】`（例：`【20260725_科技折页画册】`）
- 文件夹内部统一标配六个子目录：
  ```
  聊天记录 / 参考原图 / 需求确认文档 / 工程源文件 / 各版本稿件 / 最终交付文件
  ```
- 接单时由自动驾驶自动调用 `business_folders.py scaffold` 生成，**无需手建**。

### 3. 品类归类好处
后续封装一键技能时，可直接按文件夹归集同类案例训练模板：
海报、画册、PPT、视频分开，Agent 可快速匹配对应风格方案。

### 4. 与 ORCA 三工作树兼容不变
`worktrees`、`fleet_exchange`、`docs` 顶层不动；业务资料放在业务分类文件夹，
**代码调度层 和 业务素材层相互分开，互不干扰**。

## 四、一键创建目录结构

沙箱/受管仓库禁止直接写新目录时，请在**本机**运行以下任一脚本（已生成在 `scripts/`）：

```bash
# 方式 A：Git Bash（推荐，UTF-8 无乱码）
bash "E:/龙虾AI主控中心/我的AI分身/企业微信群定制接单项目/scripts/创建目录结构.sh"

# 方式 B：PowerShell
powershell -ExecutionPolicy Bypass -File "E:/龙虾AI主控中心/我的AI分身/企业微信群定制接单项目/scripts/创建目录结构.ps1"
```

脚本仅创建**骨架 + `.gitkeep` 占位**（确保空目录纳入 git）。具体订单的 `【日期_简述】`
项目文件夹会在接单时由 `business_folders.py` 自动生成。

## 五、归档命令

交付完成、尾款结清后，把 `01_正在执行实单/【…】` 移动到 `02_已完结归档实单/<品类>/`：
