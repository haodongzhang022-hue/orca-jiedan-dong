## 一、编排拓扑（固定）

```
企业微信接单群
   │ (inbox目录投递 / connector直拉)
   ▼
5×WorkBody 调度集群 ──汇总统一数据包(MD5校验)──▶ fleet_exchange/incoming
   ▼
Hermes大脑(mimo-v2.5-pro)：需求拆解→标准化制作指令(约束自动识别)
   ▼
Codex执行：渲染引擎四级降级(FAL→本地合成→ImageGen→Prompt)，零积分优先
   ▼
Claude Code审核：硬校验(首尾帧≤2.0/时长≤12s/背景漂移≤60/宽≥1280)+软校验
   ├─通过→ WorkBody打包(成品+底图+报价单)→企业微信群交付→私聊结算
   └─不达标→ 修改意见原路回传Codex，≤3轮迭代，不降级人工
```

## 二、两套标准流水线（择一触发）

| | 流水线A：分布式接单 | 流水线B：Hermes直驱 |
|---|---|---|
| 触发 | 群新增订单（监听自动） | 手动指令直达Hermes |
| 前置 | 5WorkBody抓取+汇总数据包 | 无 |
| 链路 | WB×5→Hermes→Codex→Claude | Hermes→Codex→Claude |
| 实测耗时基线 | ~5s（不含AI绘图） | ~4.5s |
| 适用 | 常态接单、批量轮询(route_3) | 紧急单、调试、演练 |

## 三、图生视频专用约束模板（Hermes自动识别）

固定镜头 / 灯光恒定 / 多主体同步 / 首尾帧统一 / 时长偏短(≤12s) / 原路往返镜像对称
→ 输出 `hermes_制作指令.json`（sequence时序段落 + camera/lighting双锁 + frames首尾约束）
