# 图生视频 · 逐帧校验方法论（踩坑沉淀）

**来源**：CNB Issue #63（国漫条漫书房青年 5 秒微动成片）

## 坑：把「运镜」误判成「闪烁/变形」

### 现象
用「成片帧」做全图逐帧比对时，校验项全线 FAIL：
- 相邻帧差分跳变 2.34（阈值 0.20）
- 首尾帧均值差 26.99（阈值 2.0）
- 背景跨帧 std 14.01（阈值 6.0）

但人眼看片子完全正常，无闪烁、无变形。

### 根因
1. 客户明确要求**「镜头缓慢轻微向前推」** → 帧间几何变化是**故意**的
2. 运镜实现为「等比 crop + resize」→ 每帧的取景窗口不同
3. 全图比对时，这个几何变化被当成了画面内容的抖动
4. 附带坑：逆运镜还原时若**重新居中裁切**（而非复刻真实 crop 参数），
   等于对每帧做不同变换 → 产生大量伪差异，指标反而更差

### 正确做法
1. 渲染时**同时留存运镜前素材帧**（`frames_raw/`）
2. 判定「人物是否变形 / 是否闪烁 / 背景是否漂移」→ **一律用运镜前素材帧**
3. 判定「运镜是否平稳」→ 单独用运镜参数序列（单调性 + 幅度上限）
4. 判定「成片是否等于素材 + 运镜」→ 用素材帧按真实 crop 参数复算，与成片首帧比编码误差

### 校验项与阈值（可复用）
| 校验项 | 数据源 | 阈值 |
|---|---|---|
| 分辨率/帧率/帧数/时长/编码 | ffprobe | 1920x1080 / 24fps / 120 / 5.000s / h264+yuv420p |
| 无闪烁 | frames_raw 相邻帧差分跳变 | ≤0.20 |
| 微动幅度受控 | frames_raw 相邻帧差分峰值 | ≤1.5 |
| 首尾帧统一 | frames_raw 首末帧均值差 | ≤2.0 |
| 背景无漂移 | frames_raw 墙面区跨帧 std | <0.01 |
| 面部无扭曲 | frames_raw 首末帧脸部块差 | ≤3.0 |
| 运镜平稳 | 缩放参数序列 | 单调 + ≤1.10 |
| 成片与素材一致 | 素材复算 vs 成片首帧 | ≤6.0 |

### 一致性保障（架构层，比校验更重要）
把**五官画成静态底图**，逐帧只做整体亚像素平移（呼吸位移），
口型/眼神只重绘各自局部小图（眼型、下颚线不动）→
**数学上不可能出现面部扭曲**，一致性不依赖运气。
