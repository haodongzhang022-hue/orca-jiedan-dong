二、要不要交钱

✅ 结论：起步阶段 0 元。不需要预充值、不需要买套餐、不需要绑信用卡。只要一个实名过的腾讯云账号即可。
项目规则（官方文档原文口径）
前置条件 必须绑定腾讯云账号（机时扣费由该账号承担）。腾讯云账号本身需实名认证。
首绑赠送 免费 20 个机时，自动发放到资源包，可直接抵扣消耗。一般只能领一次。
每日赠送 免费 创建应用每日活跃赠送 2 个机时（有效期为短期，以控制台实际显示为准）。
要不要绑卡 免费额度内不需要。但如果资源包被用尽、又没手动停机，会转按量付费并从腾讯云账号余额扣 → 余额为 0 则扣不动，不会凭空产生欠费，但建议主动停机。
什么算「在用」 只要停在应用的 IDE 模式页面（/a/{appid}/edit 或 /learn）就持续扣；后台、最小化照样扣。
同一个应用开多个 IDE 标签页，通常只按 1 份算。
怎么停 ① 关掉全部 IDE 模式标签页 → 系统约 10 分钟后自动释放算力；
② 或「应用管理」→ 应用卡片 →「…」→「停止使用」（推荐，立刻停）。

五、防扣费三动作（红线，务必做）

#动作为什么
1 用完立刻「应用管理 → 停止使用」，不要只关浏览器 关标签页要等约 10 分钟才释放，期间仍在扣；且资源包耗尽后系统不会自动停机
2 定期看「应用管理」里有没有还在跑的应用 后台 / 最小化一样扣机时，最容易被忽略
3 账单有 约 2 小时延迟，别被"已停止但仍收到扣费提醒"吓到 官方明确说明：以真实使用时长为准，不会误扣
保留意见：腾讯云账号银行卡/支付方式是否已绑，会影响「余额扣费」能否成功。
如果你账号里没有余额也没绑支付方式，按量付费实际扣不动 —— 这是最彻底的防扣费方式，但也会在你想付费扩容时挡住你。请按需选择。
