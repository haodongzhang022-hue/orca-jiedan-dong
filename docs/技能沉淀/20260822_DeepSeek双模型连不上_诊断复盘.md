## 二、DeepSeek 双模型「连不上」真根因（实测）

| 模型 | 免费性质 | 实测状态 |
|------|---------|---------|
| `deepseek-v4-pro` | **付费**（¥25.06/百万 token） | 无「PRO FREE」通道；CNB 免费网关白名单不含 pro |
| `deepseek-v4-flash` | 免费（官方免费 + CNB 免费至 2026-12-31） | 凭据失效，见下 |

1. **「deepseek V4 PRO FREE」不存在**：DeepSeek 官方 `deepseek-v4-pro` 是旗舰付费模型，无免费档。免费档只有 `deepseek-v4-flash`。
2. **CNB 免费 flash 凭据三处失效**（workbuddy Python ssl 实测）：
   - `bridge_cnb_npc/config/token_config.json` 内旧 token `cnb_7AuZ...` → `401 credential invalid or expired`。
   - 当前环境变量 `CNB_TOKEN` → `403 [NO_RIGHT] OpenAPI only allowed in pipeline`（只能在 CNB 流水线内调用，本机直连被拒）。
   - DeepSeek 官方 `DEEPSEEK_API_KEY` 实为占位符 `atomcode-local` → `401 invalid`。
3. **本地服务全部未监听**：`13460 / 3081 / 3080 / 15730 / 15721 / 6060 / 8080 / 8787` 均无 LISTENING 进程，网关/代理/Harness 处于停机状态。
