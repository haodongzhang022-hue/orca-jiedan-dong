## 三、闭环状态机（核心）

```
已接单(Hermes建档)
  → 执行中(codex出稿)
  → 待审核(Claude Code校验)
  → 已放行(审核通过)
  → 已交付(客户确认使用)
  ⇡ 客户提二次修改意见 ↩ 回退「执行中(codex改)」→ 重审 → 再放行 → 再验收
```

**铁律**：闭环终点不是「审核放行」，是「客户真正用上 + 无修改意见」。只要客户有意见，状态机必回退。
