# 技能沉淀卡片：knowledge_extraction_from_cloud_drive

## 基本信息
- **技能 ID**: `knowledge_extraction_from_cloud_drive`
- **技能名称**: 网盘课程知识萃取
- **版本**: 1.0.0
- **所属体系**: 龙虾舰队流水线 · 知识管理技能库
- **触发关键词**: 网盘课程、知识萃取、课程沉淀、知识库建设、课程资源整理

## 输入
1. 网盘分享链接 + 提取码（需用户授权）
2. 本地课程目录路径
3. 课程清单文件（CSV/JSON）

## 输出
1. 课程大纲.md
2. 知识点卡片库（多个 .md）
3. 思维导图.md
4. 商单交付物（基础/专业/企业版）
5. Obsidian 双知识库同步
6. skill_registry.json 注册更新

## 核心能力
- 自动扫描与索引课程目录结构
- 自动提取课程大纲、知识点、核心概念
- 自动生成课程笔记、思维导图、知识卡片
- 自动去重、分类、打标签
- 自动沉淀到 Obsidian 双知识库
- 自动生成可复用技能卡片

## 龙虾五步法对应
| 步骤 | 本技能映射 |
|------|------------|
| Step 1 精准备份 | 备份原始课程资源目录清单，不修改源文件 |
| Step 2 根因诊断 | 扫描目录结构，识别资源类型与质量 |
| Step 3 无命令不执行 | 按配置执行萃取，关键节点需用户确认 |
| Step 4 验证修复 | 质量校验，抽检准确率与覆盖率 |
| Step 5 沉淀归档 | 写入知识库、生成技能卡片、同步 GitHub |

## 能力边界
- 不破解加密课程 / 付费内容
- 不处理违法违规内容
- 不自动上传到公开平台
- 不修改原始课程文件

## 质量标准
- 萃取准确率 ≥ 90%
- 知识点覆盖率 ≥ 85%
- 结构化输出可直接用于商单交付

## 调用方式
```bash
python scripts/auto_knowledge_extract.py --input <课程目录> --output outputs
```
