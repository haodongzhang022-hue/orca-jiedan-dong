## 3. 真根因 #2：Git Bash MSYS 路径拼接

```
症状：python3 /c/Users/.../python.exe 都能找到，但脚本里调时变成：
   "C:\Users\...\python3.exe: can't open file 'E:\\e\\...'"
根因：MSYS 在调用 windows native exe 时，把 args 里的 unix 路径 /c/ 转回 C:\
     然后又把 ROOT 拼上去变 E:\\e\\...
修复：MSYS2_ARG_CONV_EXCL='*' + LOG 函数用 cd $SCRIPT_DIR + 相对路径
实测：bash scripts/run_1234.sh → 23 条活动 ✅
```
