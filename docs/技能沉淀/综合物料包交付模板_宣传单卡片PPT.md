# 综合物料包交付模板（宣传单+卡片+PPT）· 技能卡片

> 沉淀时间：2026-08-06 | 来源：ORD-20260806-001 实战 | 复用等级：⭐⭐⭐⭐⭐

## 适用场景
客户一次下单含「宣传单双面 + 多张卡片 + PPT」的组合物料需求（¥500 级实单常见形态）。

## 核心流程
1. **统一 VI 先行**：design_brief 中先锁定主色/字体/版式语言（如深海蓝+活力橙），三品类共用
2. **模板映射**：
   - 宣传单 → 折页排版模板（A5 双面，含出血/裁切线）
   - 卡片 → 宣传卡片模板（90×54mm 批量，12 个主题槽位）
   - PPT → python-pptx 四页母版（封面/目录/内容/尾页）
3. **本地免费渲染**：SVG → cairosvg；PPTX → LibreOffice+pdftoppm 预览
4. **Claude 硬校验**：印刷规范（CMYK/出血/300dpi）+ 合规（占位标注/无侵权）+ 成本毛利
5. **占位文案交付**：客户资料缺失 → 「占位」标注 + 替换清单，不伪造

## 生成脚本清单
| 脚本 | 作用 |
|------|------|
| `generate_design_v1.py` | 宣传单双面 + 12 卡片 SVG/PNG |
| `generate_ppt_v1.py` | 4 页 PPTX |
| `image_gen_requests.json` | FAL-free 适配器效果图请求 |

## 成本核算
本地渲染零积分 → 毛利 ≈ 报价金额；需 FAL_KEY 才可能产生外部费用（可选升级项）。

## 合规红线
- 占位文案必须标注「占位」，禁止伪造客户品牌/联系方式
- 字体建议开源可商用（Noto CJK），印刷前提示客户确权
- 客户 Logo/素材须获授权后才替换进正式稿
