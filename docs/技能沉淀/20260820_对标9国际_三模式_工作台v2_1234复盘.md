## 1. SVG 错误诊断与根因

### 现象
浏览器（火狐/Chrome）打开 `agency_agents_国际对标.svg` 报错：
```
This page contains the following errors:
error on line 24 at column 61: CharRef: invalid decimal value
```

### 根因（确诊）
SVG 文件里 55+ 处中文字符引用被错写为 `&#u516c;` 形式（HTML5 非标扩展），但 SVG 是 **XML**，只支持：
- ✅ `&#xHEX;` 合法
- ✅ `&#DEC;` 合法
- ❌ `&#uXXXX;` 非法（HTML5 才允许）

第 24 行第一个错处正好是 `&#u516c;`（"公"），后续 `&#u53f8;` `&#u5bf9;` `&#u6807;` `&#u67b6;` `&#u6784;` 都是同样错误。

### 修复策略
不用字符引用，**直接用纯 UTF-8 中文字符**写入 SVG（SVG 本就 UTF-8 编码）。
- 全文件 `&#u` 数量：`55+ → 0` ✅
- 全文件 `&#x` 数量：`0`（不需要了） ✅
- SVG 整体重写：`113 行 → 178 行`（含 9 公司 + 三模式对比面板 + 4 阶段路线图）

## 8. 错误案例沉淀（防复发）

| 错误 | 现象 | 根因 | 防复发 |
|---|---|---|---|
| SVG `&#u` 报错 | 浏览器 24 行红字 | XML 不支持 HTML5 非标 `&#uXXXX` | 写 SVG 直接用 UTF-8 字符，不逃逸 |
| Git Bash 转义崩 | `eval: line 1: syntax error near unexpected token '('` | 中文+括号 in 单引号 heredoc | 用 `cat > /tmp/x.py << 'PYEOF'` 隔离 |
| Grep 输出 `No matches` | 排除中文 | ripgrep 默认 utf-8 但部分调用有问题 | 改 Python re.findall 精度统计 |
| CNB push 401 | 沙箱出口 127.0.0.1:7897 死代理 | 系统代理 schannel 截 git | `git -c http.proxy=` 前缀绕 |
