## 二、工作台 v2.3 新增 6 个能力

### 🎨 顶部「📂 落盘位置横幅」

```

```

横幅永久显示，**汤哥任何时候都知道"位置"**。打开目录按钮即使被沙箱拦截，也弹自绘 modal 含 PowerShell 备用命令。

### 🎯 「📦 一键真落盘（推荐）」**新**按钮

3 步闭环（避开浏览器沙箱下载到 C 盘的死结）：

```
🅰 JSON 自动复制到剪贴板（一进 modal 即拷）
🅱 PowerShell 一行命令已展示（用户复制 + 粘贴 + 回车即真写盘）
🅲 或者点「📥 下载落盘 BAT 到 scripts/」→ 保存到 scripts/ → 双击
```

为啥必加 PS 路径？——浏览器沙箱物理无法直写本地文件，所以**唯一的真写盘路径是本地终端**。
