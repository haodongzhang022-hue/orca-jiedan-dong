## 一、一键启动

### 方式1：Bash 脚本（推荐）
```bash
bash scripts/launch_all_agents.sh
```

### 方式2：Windows 批处理
```cmd
scripts\launch_all_agents.cmd
```

### 方式3：Orca IDE 自动触发
进入项目目录时，`.orca/setup.sh` 自动执行环境就绪检查。

## 三、故障复位

### 3.1 代理端口断开
```bash
# 检查端口状态
netstat -ano | grep LISTENING | grep -E ":(15721|15730) "

# 手动拉起
start //min "Fix-15721" "C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe" "E:/龙虾AI主控中心/MCP服务/anthropic_proxy_15721.py"
start //min "Fix-15730" "C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe" "E:/龙虾AI主控中心/MCP服务/codex_tool_proxy.py"
```

### 3.2 Codex MODULE_NOT_FOUND
```bash
# 重建 shim（双格式）
cat > ~/AppData/Roaming/npm/codex << 'EOF'
#!/bin/sh
exec node "I:/npm/node_modules/@openai/codex/bin/codex.js" "$@"
EOF
cat > ~/AppData/Roaming/npm/codex.cmd << 'EOF'
@ECHO off
node "I:\npm\node_modules\@openai\codex\bin\codex.js" %*
EOF
chmod +x ~/AppData/Roaming/npm/codex
```

### 3.3 Claude Code API Error: ConnectionRefused
代理端口未启动。执行 3.1 即可。

### 3.4 全域模板调用失败
```bash
# 检查模板文件
ls -la "E:/龙虾AI主控中心/我的AI分身/技能库/龙虾全域官方模板-最终版.md"

# 检查 Hermes 技能加载
hermes skills list | grep lobster
```
