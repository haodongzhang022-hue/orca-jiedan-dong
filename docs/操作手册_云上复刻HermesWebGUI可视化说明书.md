## ⚠️ 先看这个（很多人卡在这一步）

你问的「**浏览器打开 `https://{id}-6060.cnb.run` 怎么打开**」——

**答案：`{id}` 不是让你手打的字母，它是一个占位符，必须由 CNB 平台自动生成的真实 ID 替换。**

- ❌ **错误做法**：直接复制 `https://{id}-6060.cnb.run` 粘贴进浏览器 → 会得到「没有找到该 URL」（就是你截图里那个报错）。
- ✅ **正确做法**：先启动云原生开发环境，再从 WebIDE 的 **PORTS 面板**里**复制平台生成好的真实链接**（如 `https://fjisdofi21-6060.cnb.run`）再打开。

> `{id}` 是一串每次启动都会变的随机小写字母（例如 `fjisdofi21`），**不是**你仓库的名字、也不是固定的。你无法提前猜到它，只能在启动后从 PORTS 面板拿到。

## 二、逐步操作（图文步骤）

### 第 1 步：进仓库 → 点「云原生开发」按钮

1. 打开仓库：`https://cnb.cool/TJF19770107/orca-jiedan`
2. 在**分支页**（或仓库主页顶部）找到 **「云原生开发」** 按钮
3. 点击它 → CNB 开始创建云端开发环境

> ⚠️ 如果你点「云原生开发」没反应或报错，多半是 `.ide/Dockerfile` 构建失败——PR #35 已把基础镜像 tag 修成 `v0.6.39`，如果还没合入就先去合入。

### 第 2 步：等镜像构建 + 环境就绪

- CNB 会先构建/拉取 Hermes Web UI 镜像（约 1.5GB，**第一次会比较久**，属正常）
- 构建完成后自动进入 **WebIDE 浏览器窗口**（就是一个 VS Code 风格的网页编辑器）
- 这是你能「看见容器」的地方：左边是文件树、下面是终端、有 PORTS 端口面板

### 第 3 步：打开 PORTS 面板 → 添加 6060 端口映射

在 WebIDE 底部（或右侧）找到 **「PORTS」/「端口」** 面板：

1. 点 **「添加端口 / Add Port」** 或输入框
2. 填入 **`6060`**
3. 回车 → CNB 自动在面板里生成一条访问地址

### 第 4 步：复制平台生成的真实地址（关键！）

**这一步就是你卡住的地方。** 面板生成后会出现类似：

```
https://fjisdofi21-6060.cnb.run
```

- **不要**手打，**直接点面板里那行地址**，或点复制图标复制到浏览器打开
- 那串 `fjisdofi21` 就是「真实的 id」，由 CNB 自动分配，每次启动可能不同
- 面板地址栏右侧通常有 **「在浏览器打开 / Open in Browser」** 的小图标，直接点即可

### 第 5 步：确认进入 Hermes Web 控制台

浏览器打开真实地址后：

- 看到 **Hermes Studio Web 控制台**（登录/聊天界面）即成功
- 在控制台「模型管理 / Providers」里确认 provider 指向 **`127.0.0.1:8787`**（适配层）
- 发送一句话，能正常回复 = 已连通 CNB 免费基座 `deepseek-v4-flash`（0 成本）

## 四、常见问题（FAQ）

### Q1：我直接打开 `https://{id}-6060.cnb.run` 报「没有找到该URL」？
→ 因为你把占位符 `{id}` 当成了真地址。**必须**先从 WebIDE「PORTS」面板复制平台生成的真实地址（`https://<随机id>-6060.cnb.run`）再打开。

### Q2：PORTS 面板里没有 6060？
→ 手动「添加端口」输入 `6060`；若还是没有，检查容器内服务是否真的监听 `0.0.0.0:6060`（`.ide/Dockerfile` 已设 `BIND_HOST=0.0.0.0`，正常会在）。

### Q3：为什么每次地址不一样？
→ `{id}` 是 CNB 给每个开发环境实例分配的临时子域标识，环境重建就换一次。**每次都要从 PORTS 面板重新复制。**

### Q4：这个云上环境能一直挂着吗？
→ **不能常驻**。有回收机制：创建后 10 分钟无操作 / 最大保持 18 小时 / 使用超 8 小时且凌晨 4-6 点会强制回收。定位是**出差/兜底**，日常编排建议用本地桌面版 Hermes Studio。

### Q5：地址打不开，是不是端口映射要改？
→ 确认端口面板映射的是 **6060**，不是别的端口；且 Hermes Web UI 监听 `0.0.0.0`（不能是 `127.0.0.1`，否则 CNB 端口预览访问不到）。
