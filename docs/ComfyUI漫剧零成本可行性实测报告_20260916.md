### 2.3 启动实测：能起，但被"联网重试"卡住

启动 `main.py --cpu --port 8188` 三次实测：

| 次数 | 配置 | 结果 |
|---|---|---|
| ① | 默认代理，30s 采样 | 进程存活，仍在依赖自检（Manager 预启动耗时 17s） |
| ② | 默认代理，180s 采样 | **节点全部加载成功，但 8188 始终未监听**；STDERR 出现 `[LibAI Client] Connection failed: [WinError 1225] 远程计算机拒绝网络连接` 无限重试 retry=7…10 → 启动被拖死 |
| ③ | 清代理 + `--disable-all-custom-nodes` | **进程直接崩**：`ModuleNotFoundError: No module named 'manager_core'` |

**根因（已定位）**：

1. **代理拦截**：本机环境变量 `HTTP_PROXY = http://127.0.0.1:65217`（沙箱/隧道代理，拒绝连接）。LibAI 客户端启动时要回连 liblibai 服务器做增量更新与缓存拉取，被拒后进入无限重试循环 → 阻塞服务绑定端口。
2. **`--disable-all-custom-nodes` 是本整合包的死路**：`ComfyUI\main.py:369` → `libai_server\libai_client.py` → `router.py` → `plugin.py:16` → `import manager_core`，而 `manager_core` 位于 `ComfyUI-Manager\glob\`。禁用节点后该模块不在 sys.path → 必崩。**切勿用此参数排障。**

## 三、三方案判定（本机 / CNB / 香港服务器）

| 方案 | GPU | 成本 | 出图 | 出视频（漫剧核心） | 判定 |
|---|---|---|---|---|---|
| **本机 CPU ComfyUI** | 无（核显无用） | 0 元 | ✅ 可行（SDXL-Turbo 4步，512×768 约 1~3 分钟/张） | ❌ 不现实（Wan2.2-5B 单条 5 秒视频 CPU 需数小时~数十小时） | **只做图片线** |
| **云端 CNB（cnb.cool）** | 共享 GPU（L40/H20） | ❌ **已收费** | — | — | **排除** |
| **香港 2核4G** | 无 | 0 元 | ❌ 4GB 内存 < SD1.5 需求（约 4~6GB） | ❌ | **只做调度/存储/隧道** |

**CNB 关键变更（核对腾讯云官方计费文档）**：
- 云原生开发 CPU 免费额度 **1600 核时/月**（8核16G 可跑 200 小时）→ 仍然免费
- 云原生构建 CPU 免费额度 **160 核时/月**
- **⚠️ 自 2026-08-01 起，CNB 取消「云原生构建-GPU」与「云原生开发-GPU」的免费额度**，GPU 按量付费 **0.5 元/核时**
- → 所以 CNB 仍可用于**代码托管 + CPU 编排 + 六端归档**，但**不能当免费 GPU 推理池**。

## 四、零成本正解：双引擎链路

### 引擎 A（视频线主力）：腾讯 Cloud Studio

> **⚠️ 数据修正（2026-09-16 复核）**：本节初版写「每月 10000 分钟 GPU 免费」，那是 **2025 年的旧政策**（腾讯云当时开发者文章口径）。
> 核对**官方计费文档（更新于 2026-08-11）**后确认：**现行已改为「机时制」，无「每月 1 万分钟」这一口径**。以下为修正后的准确数据。

**入口（均已 HTTP 实测 200）**

| 入口 | 地址 | 说明 |
|---|---|---|
| **主入口（推荐）** | https://cloudstudio.net/ | 主站兼控制台，官方文档全部指向此域名 |
| 旧域名 | https://ide.cloud.tencent.com/ | 实测仍 200 可访问，会落到 Cloud Studio |
| 产品页 | https://cloud.tencent.com/product/cloudstudio | 计费与购买说明入口 |

**免费额度机制（官方文档口径）**

| 项目 | 值 |
|---|---|
| 前置条件 | **必须绑定腾讯云账号**（机时扣费由该账号承担），腾讯云账号需实名 |
| 首次绑定赠送 | **20 个机时**（自动发放到资源包，一般只能领一次） |
| 每日赠送 | 创建应用 **每日活跃赠送 2 个机时**（短期有效，以控制台为准） |
| 免费规格 | **GPU T4 · 16GB 显存 · 8核 · 32GB 内存** |
| 抵扣因子 | **T4 = 1.2 机时/小时** → 20 机时 ≈ **16.7 小时 T4** |
| 网络 | 国内直连，无需代理（这点比 Colab/Kaggle 强） |
| 超量单价 | T4 按量付费 **1.2 元/小时**；资源包 0.85~1.00 元/机时（按购买量阶梯） |
| 实测参考 | 社区实测 T4 上跑 Wan2.1 图生视频，10 秒 480p 约 **3 分钟** → 1 小时出 20 条，白送额度可出 **约 333 条** |

**⚠️ 防扣费红线（官方文档明确）**
1. 资源包机时耗尽后，**系统不会自动停止应用**，会**自动切换按量付费**从腾讯云账号余额扣 → 用完必须手动停。
2. 只要停在 **IDE 模式**页面（`/a/{appid}/edit`、`/learn`）就持续扣，**后台/最小化照样扣**。
3. 停止方式：关闭**全部** IDE 标签页（约 10 分钟后自动释放，期间可能产生少量费用），或「应用管理」→ 应用卡片 →「…」→ **「停止使用」**（推荐）。
4. 账单有 **约 2 小时延迟**，可能出现"已停止但仍收到扣费提醒"，以真实时长为准。

**部署三行命令**：

```bash
git clone --depth 1 https://github.com/comfyanonymous/ComfyUI.git && cd ComfyUI
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
python main.py --listen 0.0.0.0 --port 8188      # nvidia-smi 先确认 GPU
```

模型从魔搭下载（国内 CDN 可达 100MB/s，远快于 HuggingFace）。

## 五、漫剧零成本 SOP（7 步全链路）

| 步 | 环节 | 用哪个引擎 | 零成本手段 | 备注 |
|---|---|---|---|---|
| 1 | 剧本 / 分镜文本 | 本机 | TeamoRouter 免费池 `deepseek-v4-flash-free` | 已有链路 |
| 2 | 分镜提示词 | 本机 | 已有技能 `MiniMaxH3分镜提示词生成器` | 直接复用 |
| 3 | 角色立绘 + 分镜图 | **本机 CPU ComfyUI** | SDXL-Turbo 4步 / SD1.5+LCM | 1~3 分钟/张，一晚可出 30~50 张 |
| 4 | 角色一致性 | 本机 CPU | InstantID / IPAdapter（节点已就位，补下模型） | CPU 较慢，批量放夜间 |
| 5 | 图生视频 | **Cloud Studio 免费 T4** | ComfyUI + Wan2.2-I2V / TI2V-5B | 漫剧的"动起来"关键步 |
| 6 | 配音 | 本机 | `edge-tts`（微软免费 TTS） | 已有 `zero-cost-video-render` 技能 |
| 7 | 剪辑合成 | 本机 | ffmpeg 拼接 + 字幕 | 已有技能 |

**生产成本实测口径**：图片线 0 元 0 积分；视频线 0 元（吃云端免费额度）；仅消耗电费 + 时间。

## 六、风险与红线

1. **免费额度是"临时弹药"不是基础设施**：魔搭/Cloud Studio 的免费规格会静默调整（参考 Zen 席位 29 天 5 下架 4 新增的教训）→ 每月 diff 一次额度页。
2. **不要绑卡**：任何"免费但需绑信用卡/自动续费"的 GPU 池，一律不进生产链路。
3. **数据别喂免费池**：客户商单素材（尤其人像）在免费公共实例上跑，注意零保留政策与服务条款。
4. **本机代理与 ComfyUI 冲突**：沙箱/隧道代理会拖死 LibAI 客户端；**本机启动 ComfyUI 前必清 HTTP_PROXY**。
5. **磁盘**：D 盘 7.8GB、C 盘 20.6GB 已告急；模型只落 G 盘（206GB）。下载模型前先确认目标盘 ≥ 30GB。
