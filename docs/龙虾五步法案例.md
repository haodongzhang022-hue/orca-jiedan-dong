# 龙虾五步法案例：企业微信群定制接单项目

## 案例名称
建设「网盘课程资源知识萃取与沉淀体系」项目，实现课程资源自动萃取 → 结构化沉淀 → 商单变现。

## 案例背景
用户积累了多份网盘付费课程资源，希望：
1. 不下载大体积视频，只萃取核心知识与 SOP；
2. 沉淀到 Obsidian 双知识库；
3. 形成可复用技能，后续多 Agent 舰队可自动执行；
4. 最终输出可商单交付的笔记/思维导图/培训方案。

## 龙虾五步法执行实录

### Step 1 精准备份
- 操作：扫描课程目录结构，生成 `source_manifest.json` 备份清单，不复制大文件。
- 原则：不修改任何原始课程文件，只读取目录与文件名信息。
- 产物：`backups/<timestamp>/source_manifest.json`

### Step 2 根因诊断
- 操作：识别资源类型（视频 / PDF / Word / 文本 / 音频），统计文件数与大小，估算处理时长。
- 判断：文本类文件可完整读取；视频/音频依赖本地 ffmpeg + whisper；模型后端默认 Ollama。
- 产物：日志中的扫描结果与资源类型分布

### Step 3 无命令不执行
- 操作：按 `config/default_config.yaml` 与 `config/model_config.yaml` 执行萃取；
  - 文本分段 → 模型摘要 → 知识点提取 → 模板渲染 → 知识库同步。
- 授权：首次访问新目录、涉及大量文件操作、同步外部平台前询问用户。
- 产物：`outputs/` 下的大纲、知识卡片、思维导图、商单交付物

### Step 4 验证修复
- 操作：抽检输出文件是否生成、关键字段是否非空、知识卡片数量是否达标。
- 标准：萃取准确率 ≥ 90%、知识点覆盖率 ≥ 85%。
- 降级：模型不可用时自动回退 mock，记录日志提示用户配置模型。

### Step 5 沉淀归档
- 操作：
  1. 写入 Obsidian 主库（`E:/.../副业项目库`）与备份库（`G:/...`）
  2. 更新 `skill_registry.json` 注册本技能案例
  3. 生成 `docs/技能沉淀/知识萃取技能.md` 技能卡片
  4. 项目文件提交到 Git 仓库，并同步到 GitHub 私有仓库（后续配置）
- 产物：技能卡片、商单交付模板、Git 提交记录

## 经验复用
- 同样流程可用于企业内部培训课程、行业研报、播客节目等知识源。
- 只需替换输入目录与课程分类标签，萃取引擎与模板即可复用。
- 多 Agent 舰队可调用 `scripts/auto_knowledge_extract.py`，实现自动化流水线。

## 风险与合规
- 不破解、不传播付费课程原文件。
- 输出物为结构化学习笔记，仅供内部使用。
- 原始课程版权归原课程方所有。
