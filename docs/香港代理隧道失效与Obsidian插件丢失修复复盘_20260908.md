# 香港代理隧道失效与 Obsidian 插件丢失修复复盘（2026-09-08）

> 全程本地零积分。汤哥全权委托自动修复，本笔记 = 根因 + 修复 + 固化，供后续复盘。

## 一、香港代理 Chrome「ERR_PROXY_CONNECTION_FAILED + 谷歌账号同步失败」

**链路真相**：
- 桌面「启动Chrome香港代理.bat」= 独立 Chrome 实例（`--user-data-dir=...\Chrome\ProxyProfile`），走 `socks5://127.0.0.1:1081`
- 1081 = SSH 动态隧道（`ssh -N -D 1081 root@43.161.202.206`，密钥 `~/.ssh/id_ed25519`）
- 常驻 = 计划任务 `Lobster_HKTunnel`（AtLogOn 跑 `C:\Users\Administrator\hk_proxy_tunnel.bat`）

**根因链**：重启后 `Lobster_HKTunnel` 未成功执行（LastRunTime=1999/11/30 从未跑成）→ 1081 无人监听 → Chrome 代理连不上（ERR_PROXY_CONNECTION_FAILED）→ Google 账号同步连带失败。**不是 Chrome 配置问题，不是账号问题。**

**深挖出的 3 个隐患（本次全部修掉）**：
1. `hk_proxy_tunnel.bat` 用裸 `ssh` → 计划任务环境下 PATH 不可靠 → 改全路径 `C:\Windows\System32\OpenSSH\ssh.exe`
2. bat 里 `timeout /t 5` = cmd 静默杀手②（Git-Bash GNU timeout 抢占 → invalid time interval → 重连循环死）→ 全部改 `ping -n N 127.0.0.1 >nul`
3. 桌面 bat 注释误写「Clash Verge mixed-port 7897」与实际参数 1081 矛盾（误导排障）→ 注释改为真实链路

**修复动作**：
- 立即恢复：Python `subprocess.Popen`（DETACHED_PROCESS）拉起 ssh 隧道脱离会话常驻 → `netstat 1081 LISTENING` + curl 经 socks5h 访问 Google 返回 **200**
- 固化：重写 `hk_proxy_tunnel.bat` / `hk_proxy_guard.bat` / `启动Chrome香港代理.bat`（GBK+CRLF+回读验证，备份 `.bak_20260908_1805`）
- 注意：`ssh -f` 在 Git Bash 会把整个 Bash 会话搞崩（输出全吞 exit 1），**分离常驻必须走 Python Popen detached**

**同步失败善后**：隧道恢复后重开 Chrome，Google 账号同步自动重连，书签文件夹会从云端账号回流，与本地带AI标识浏览器（SPChrome）同账号趋同，无需手动搬。

## 二、Obsidian「设置→第三方插件」空了

**核查结论（community-plugins.json 其实都在）**：
- `obsidian-copilot`（Copilot 4.0.6）**代码完好**，data.json 配置完好（defaultModelKey=deepseek-v4-pro-free|openai）
- 但 **dataview / excalidraw / kanban / templater 四个插件只剩 data.json 设置残骸，main.js/manifest.json 全丢** → 插件列表看起来「空了」

**修复动作**：
1. 四插件重装：GitHub releases API 拿最新版 → main.js/styles.css 走 `gh-proxy.com` 前缀（直连 10054/10060 全挂）→ manifest.json release 资产 3 个拉不到 → 改走 **jsdelivr `cdn.jsdelivr.net/gh/{repo}@{tag}/manifest.json`** 成功
2. **manifest id ≠ 文件夹名**（关键坑）：excalidraw→`obsidian-excalidraw-plugin`、kanban→`obsidian-kanban`、templater→`templater-obsidian`、obsidian-copilot→`copilot`。community-plugins.json 注册的是 **manifest id**，按文件夹名注册全是悬空条目 → 已按真实 id 全部修正
3. 重启：taskkill Obsidian → 计划任务 `Lobster_ObsidianLaunch` → 5 进程正常

**通用教训**：插件「消失」先查三处再动手——①文件夹里 main.js/manifest.json 在不在 ②community-plugins.json 注册的 id 与 manifest id 是否一致 ③是否存在同名/悬空条目。别一上来就重装。
