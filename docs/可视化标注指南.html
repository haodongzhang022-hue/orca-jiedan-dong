附：两段标准脚本（复制即用）

标准设置脚本（龙虾五步法 Step1 环境备份） — 填入页面1/页面2「设置脚本」框：

# ORCA多Agent工作树自动初始化脚本 | 龙虾五步法Step1环境备份
# 继承全域模板环境变量，自动同步项目配置、依赖、知识库软链接
cp "$ORCA_ROOT_PATH/config/default_config.yaml" "$ORCA_WORKTREE_PATH/config/"
cp "$ORCA_ROOT_PATH/.env" "$ORCA_WORKTREE_PATH/.env"
# 自动加载龙虾舰队统一依赖
pip install -r "$ORCA_ROOT_PATH/requirements.txt"
# 绑定Obsidian知识库软连接（G盘，不占本地/GitHub存储）
mklink /D "$ORCA_WORKTREE_PATH/obsidian_link" "$OBSIDIAN_MAIN"
# 自动注册当前分支技能至总skill_registry.json
python "$ORCA_ROOT_PATH/scripts/skill_auto_register.py" --tree "$ORCA_WORKTREE_PATH"
echo "✅ 工作树初始化完成，龙虾五步法环境加载完毕"

标准存档脚本（龙虾五步法 Step5 沉淀归档） — 填入页面2「存档脚本」框：

# 工作树归档清理脚本 | 龙虾五步法Step5沉淀
echo "开始归档工作树：$ORCA_WORKSPACE_NAME"
# 自动备份日志、输出物至统一备份目录（E盘，禁C盘）
cp -r "$ORCA_WORKTREE_PATH/logs" "$LOBSTER_BACKUP_ROOT/$ORCA_WORKSPACE_NAME"
# 自动同步变更至Git仓库
cd "$ORCA_WORKTREE_PATH"
git add .
git commit -m "auto archive: $ORCA_WORKSPACE_NAME 工作树归档"
echo "✅ 工作树归档沉淀完成，同步至私有Git仓库"

注：脚本内 $OBSIDIAN_MAIN / $LOBSTER_BACKUP_ROOT 取自项目根 .env（已随设置脚本复制进工作树），避免写死绝对路径，符合全域模板边界约束。

全自动填充 vs 手动对照

🟢 场景①：全自动自动填充（推荐）

首次新建 ORCA 项目 / 生成 3 个 Agent 工作树时，系统读取全域模板内置配置，一次性填充全部设置脚本、路径、运行规则，用户仅确认授权，零手动输入。

自动校验：

覆盖 ORCA 默认 C 盘路径 → E 盘 注入两段标准脚本 开启「等待设置完成」开关 绑定 Obsidian 软链 自动注册技能

🔵 场景②：手动填写对照

日后手动配置时，按上方 3 页逐框标注与对照表逐项填写即可，无需重新理解逻辑。

关键点速查：

工作树位置=E盘模板 何时跑步=默认运行 开关=开启 分支=3个关键词 脚本=两段标准
