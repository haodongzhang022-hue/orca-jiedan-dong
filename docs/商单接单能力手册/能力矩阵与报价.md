## 一、能力矩阵

| 能力项 | 海报设计 | 视频物料 | 数字人口播 |
|---|---|---|---|
| **核心交付物** | 主视觉海报（竖版3:4/9:16） | 封面+分镜图+文案 | 口播视频(口型同步)+脚本 |

## 二、三档报价

### 2.1 演练档（内部，不对外交付）
- 用途：流程跑通、提示词沉淀、话术训练
- 报价：`00_模拟演练案例库/` 内部备案，不计入对外报价
- 凡 < ¥300 订单一律归入本档

### 2.2 零售档（真实付费）
| 品类 | 基础交付 | 建议报价 | 修改 |
|---|---|---|---|
| 🎨 单张海报 | 1 主视觉 + 1 文案 | **¥300~600** | 1 次 |
| 🎬 短视频物料包 | 封面 + 3 分镜图 + 文案 | **¥400~800** | 1 次 |
| 🗣 数字人口播 | 30-60s 口播视频 + 脚本 | **¥500~1000** | 2 次 |
| 📖 画册/折页(≤8P) | 排版+文案+源文件 | ¥600~1500 | 2 次 |

### 2.3 企业批量档（面议）
- 按月/按量阶梯：月包 ≥10 单享 8 折，专属素材库归客户
- 需微信文字确认，明确授权范围（个人非商用 / 企业商用）

## 三、成本核算规则（Claude 终审强制项）

| 品类 | 主要成本 | 毛利门槛 |
|---|---|---|
| 海报 | 文生图积分（SVG/ImageGen 免费则≈0） | 毛利 > 0 |
| 视频物料 | 关键帧图像生成 | 毛利 > 0 |
| 数字人口播 | 云端平台费(可选) / 本地≈0 | 毛利 > 0 |

> 计算方式：毛利 = 报价 − 实际积分/平台消耗。毛利 ≤ 0 → Claude 终审给出「调价 or 拒单」结论。

## 五、纠纷应对速查

| 场景 | 应对话术 |
|---|---|
| "免费多改几版" | 本次含 N 次修改已含在报价内，额外版本按 ¥N/版 计费 |
| 中途大改 | 属新增范围，补 ¥N 并顺延 N 天 |
| 不付尾款 | 成品已按约交付，请于 N 日前结清；逾期暂停后续合作 |
| 要源文件 | 源文件含 ¥N 授权费（或已含在批量档） |
| 要求照搬某海报 | 可借鉴风格，不直接用原素材/Logo（版权红线），重做原创版 |
