## 一、接单 5 段工作流（接单就照这个走）

### STEP 1 · 接单解析（30s）
- 触发：从企业微信群收到客户需求
- 工具：Marvis v0.2.1 OCR 或手动粘贴到工作台「群消息实时看板」
- 自动：解析价格 / 关键词 / 分类 / 入订单池
- 输出：`订单池 → 点击选中`

### STEP 2 · 报价 & 排期（30s）
- 公式：`报价 = 客户预算 × 65%~75% + 稀缺品类溢价`
- 溢价表：

| 品类 | 常规区间 | 稀缺溢价 |
|---|---|---|
| 图文排版 | ¥60-300 | - |
| 海报设计 | ¥30-200 | 国际海报 +30% |
| 文案类 | ¥20-80 | - |
| 数字物料 | ¥50-150 | - |
| 报纸样张 | ¥150-400 | +50% |

- 话术：工作台「资源中心 → 报价公式 → 一键复制」

### STEP 3 · 生产（0 工具成本）
- 工具栈：
  - 文案：DeepSeek V4 Flash（免费至 2026-12-31）
  - 设计：仓颉 Skill 蒸馏素材库 + agency-agents/design/8 角色
  - 视频：HyperFrames（HTML→PNG，海报零成本）
  - 重思考：GLM-5.2 NVIDIA 旁路

### STEP 4 · 交付（一键 5 件）
- 工作台「一键交付」按钮 → 自动生成：
  1. 订单概况
  2. 报价话术
  3. 交付话术
  4. 复盘模板
  5. SKILL 增量标签
- 一键复制全部 → 群里粘贴给客户

### STEP 5 · 沉淀（每单必做）
1. 工作台「📦 沉淀到 SKILL」按钮
2. 调用 1234 [4] 四化迭代
3. 同步到 `docs/接单SOP/品类/{cat}.md`
4. 同步到 Obsidian `wiki/{cat}/`
5. SelfLearn_Record.md 头部新条目
