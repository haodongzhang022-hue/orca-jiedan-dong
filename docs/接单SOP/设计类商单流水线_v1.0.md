## 一、Step1 意图识别 · 炼精化气

**核心目标**：从群里情报识别"我能接什么单"。

### 我方能力图谱
1. **AI 出文/出图**：DeepSeek V4 + MiMo V2.5 Pro（免费至年底）
2. **批量出图**：HyperFrames（HTML→图片帧）+ Agnes AI 视频
3. **知识蒸馏**：仓颉 Skill（私域沉淀）+ 赛博书屋（v1.5）
4. **人工微调**：必备 20% 人工审校（这是接单真实溢价的核心）
5. **浏览器自动化**：Marvis v0.2.1（看群/回复/接图）

### 我方适配订单
| 类型 | 适配度 | 单价区间 | 备注 |
|------|--------|----------|------|
| 图文排版 | ★★★★★ | ¥60-300 | 最爱单，新人坑位主力 |
| 海报设计 | ★★★★ | ¥30-200 | AI 模板快出 |
| 文案类 | ★★★★★ | ¥20-80 | 边际成本近零 |
| 数字物料 | ★★★★ | ¥50-150 | 长图/小程序图/朋友圈图 |
| 报纸样张 | ★★★ | ¥150-400 | 稀缺品类，需沉淀模板库 |

### 红线（不接）
- 涉及医疗/金融/法律合规的物料

- 报价超过 ¥1000 的"看上去很香"的单（新人坑位接不动）
- 群里刷单的（警惕被骗稿）

## 三、Step3 方案规划 · 炼神还虚

**核心目标**：从"看到单子"到"什么时候、用什么、给什么价"全自动决策。

### 报价公式（成本×安全边际·马斯克巴菲特双雄蒸馏）
```
我方报价 = (客户预算 × 0.65) ~ (客户预算 × 0.75)
       = AI 出初稿成本(0) + 人工微调时间成本 + 20% 安全边际
       + 稀缺品类溢价（报纸样张 +50% / 国际海报 +30%）
```

### 接单 SOP（5 步自动化）
```
[1/5] 实时监听 (Marvis 浏览器插件 + 计划任务)
  → 检测关键词："群内扣 1"、"有意私客服"、"封面到手"、"内页"、"海报"、"文案"
  → 自动截屏 → 蒸馏关键词 → 写进接单池（localStorage wb_jiedan_v1）
    ↓
[2/5] 报价研判 (1 分钟内心决策)
  → 是否在红线内？ ✓ 继续 / ✗ 跳过
  → 我方能力匹配？ ★★★★ 以上
  → 客户预算 vs 我方报价公式 → 自动计算
    ↓
[3/5] 群内扣 1 抢单 (人工+自动辅助)
  → 复制话术 → 群里发 "1" → Marvis 检测客服对接消息 → 进私聊
    ↓
[4/5] 初稿生成 (DeepSeek/MiMo/HyperFrames 流水线)
  → 文案生成 (2 分钟)
  → 视觉初稿 (3 分钟)
  → 客户预览 (即时发图)
    ↓
[5/5] 交付收尾
  → 终稿微调 (人工 20%)
  → 客户确认 → 收款 → 群里反馈升级 (助推满20单)
```

### 反向思考（芒格式 · 何时不接）
- 客户没明确需求 → 不接（80% 会改稿改到崩溃）
- 客户预算 < ¥30 文案类 → 不接（边际成本都打不平）
- 客户报价远低于 AI 成本 → 不接（这类客户通常穷疯）
- 群里刷单链接/二维码 → 不接（十有八九是骗子）

## 四、Step4 自主执行 · 炼虚合道

**核心目标**：AI 自主接单、人审核终稿、最少干预。

### 全自动化执行清单

#### A. 信息采集层（零积分）
```bash
# Marvis 浏览器插件监控
- 打开企业微信 → 切到 B平面设计【新人接单⑥群】
- 计划任务：每 5 分钟刷新一次页面 → OCR 识别新消息
- 关键词命中 → 写入 fleet_exchange/incoming/设计接单/<时间戳>.md
```

#### B. 智能研判层（零积分，用本地模型）
```bash
# Heroes + DeepSeek V4 联合研判
hermes 接单研判 --input fleet_exchange/incoming/设计接单/<最新>.md
  → Step1 识别单类型 / 客户 / 单价
  → Step2 是否能接（红线检查）
  → Step3 报价计算（公式应用）
  → Step4 输出研判报告 → 写入 .workbuddy/接单研判/<时间戳>.md
  → Step5 推送通知（Marvis 浏览器浮窗 + 企业微信消息）
```

#### C. 报价+执行层（人类决策 + AI 工具）
```bash
# 人工确认后，AI 出初稿
codex 执行 --order <订单ID>
  → 文案：DeepSeek V4 Flash 生成（30s）
  → 视觉：HyperFrames HTML→PNG（60s）
  → 终稿：人工微调（10-30 min）
  → 交付：发客户私聊
```

#### D. 沉淀层（零积分）
```bash
# 每次交付后自动沉淀
claude 审核 + 沉淀 --order <订单ID>
  → 写入 Obsidian wiki/接单变现/设计类接单/
  → 复盘 SOP 入库 design_jiedan_skill_v1.0
  → 蒸馏接单话术 → agency-agents/marketing/copywriter SKILL.md 增量
```

## 五、Step5 反思进化 · 蒸馏升级

**核心目标**：每接一单，沉淀一笔经验，蒸馏一个 Skill 单元。

### 沉淀四件套
1. **接单话术库**：`docs/接单话术/每周话术_2026-W34.md`（每周聚合）
2. **客户微画像库**：`docs/接单SOP/客户微画像/{客服名}.md`（每个客服留一份）
3. **设计模板库**：`docs/接单SOP/模板库/{品类}/v{N}.html`（稀缺品类优先沉淀）
4. **复盘笔记**：`Obsidian/wiki/接单变现/设计类接单复盘_YYYYMMDD.md`

### 进化度量
- **单数**：当前 0 单 / 目标 20 单（升级单价群）
- **单价曲线**：60 → 100 → 150 阶梯式提价（每 5 单复盘一次）
- **AI 出稿占比**：≥ 70%（其余 30% 人工）
- **客户回头率**：≥ 30%（20 单里至少 6 单回头）
