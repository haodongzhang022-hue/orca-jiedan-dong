# 设计类商单流水线（平面设计 + 网页设计标准化）

> 版本：v1.0 | 创建：2026-08-12 | 挂载：全域模板 · 龙虾五步法 | 实测基线：2026-08-12 task08121841139602（夜星空01 · PSD+HTML网页+Word交付）
> 定位：企业微信群【新人接单@群】设计类商单（Logo/Banner/海报/宣传单/PPT/网页）的接单→交付→沉淀全自动流水线

---

## 一、流水线拓扑（固定五步闭环）

```
企业微信群派单（截图/文字）
   ▼ Step1 接单解析：OCR截图→需求结构化（交付物/规格/尺寸/风格/报价）→ 01_正在执行实单/任务卡
   ▼ Step2 能力映射：技能库匹配（agency-agents/design 等）→ 参考图归档 assets/ → 报价确认
   ▼ Step3 执行设计：PSD/Logo/Banner/海报 → HTML+CSS 网页 → Word交付文档 → outputs/
   ▼ Step4 审核验收：CLAUDE CODE 按验收标准核对（尺寸/格式/文件齐全/风格对齐）
   ├─ 通过 → Step5
   └─ 不达标 → 修改意见原路回传执行侧，≤3轮迭代，不降级人工
   ▼ Step5 沉淀归档：案例回灌 Obsidian/副业变现 + 实单案例库 + 技能迭代（自我进化）
   ▼ 交付上传：企业微信群交付 → CNB云原生仓库归档 → GitHub同步
```

## 二、关键节点分工（三Agent）

| 节点 | 角色 | 职责 | 交付物 |
|---|---|---|---|
| 接单解析 | hermes（大脑） | OCR读图→需求结构化→任务卡 | `01_正在执行实单/【日期_客户_需求】/任务卡.md` |
| 设计执行 | codex（执行） | 出PSD/HTML/Word稿 | outputs/ 各版本稿件 |
| 审核验收 | CLAUDE CODE（审核） | 尺寸/格式/文件齐全性硬校验 | review_report.md |
| 沉淀进化 | hermes + 全员 | 案例回灌Obsidian + 技能迭代 | wiki案例 + SKILL.md升级 |

## 三、网页设计专项（HTML+CSS 交付物）

| 项 | 标准 |
|---|---|
| 工具 | 可视化Web开发_三栏工位式技能（已入技能库） |

## 五、自我进化（自我净化 = 自我进化，非缓存清理）

1. **每单闭环**：交付复盘写入 `docs/技能沉淀/` + Obsidian wiki → 蒸馏为可复用技能
2. **技能迭代**：新风格/新工具 → `SKILL.md` triggers 增补 → 关键词自动唤起
3. **知识回灌**：客户偏好（风格/配色/报价）→ `Obsidian/副业变现` 设计偏好模板
4. **对标学习**：每日定时任务（09:00）自动搜 GitHub/B站 设计教程 → 赛博书屋萃取 → wiki入库
5. **沉淀即进化**：每条案例都反向优化流水线本身，让下一单更快更准

## 七、铁律

1. 模拟单（<300元或模拟）归 `00_模拟演练案例库/`；实单（≥300）归 `01_正在执行实单/`
2. 产出一律落项目 outputs/，禁占C盘；大素材走G盘数据池
3. 每单闭环后：日志归档 + 报告归档 Obsidian + git 双推 CNB/GitHub
4. 成本铁律：优先本地免费算力（PSD用矢量/模板合成优先，Figma/Canva免费额度次之），无付费API
5. 不干扰 Marvis/MT5/CloudBase 链路
