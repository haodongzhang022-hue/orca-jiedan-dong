# 接单策略与分层报价规范

> 项目：企业微信群定制接单项目 | 生效：2026-07-25 | 方法论：龙虾五步法 V2.7 + 全域模板 #289/#290
> 定位：所有商单的报价、边界、纠纷应对统一依据。WorkBuddy 调度中枢与三工作树（Hermes/Codex/Claude）共同遵守。

---

## 一、低价单战略定调（先讲清楚"什么不接"）

### 1.1 行业低价单（40~80 元）持续存在的真实原因
1. **普通用户部署门槛极高**：Codex / Claude Code / 各类 AI 绘图 Agent 虽有开源免费版，但环境依赖复杂（Node 版本、端口隔离、模型权重、代理、Windows 沙箱权限），报错无解，普通用户折腾数小时跑不起来。
2. **免费工具隐性成本高**：每日次数上限、高清导出收费、商用版权受限、批量卡顿；本地开源工具虽无次数限制，但部署调试排错的**时间成本**极高。
3. **客户"摸鱼式外包"心态**：客户自己会简单用 AI，但不想反复调提示词、排版、修瑕疵，花钱买时间、省操作，本质轻量外包。

### 1.2 低价单的弊端（优先规避）
- 收益极低：40~80 元单，沟通 + 多轮修改 + 排版耗时 2~4 小时，时薪远低于 300 元级商单。
- 预期混乱：低价客户普遍要求多轮免费改、临时大改，极易纠纷。
- 资源挤占：大量低价单占用 Agent 算力、工作树调度，耽误高价值大单。

### 1.3 仅存的少量价值（有限接纳 → 仅内部训练）
- 用于**内部模拟演练**：沉淀提示词模板、标准化沟通话术，完善商单技能库。
- 积累通用素材库：摇滚海报、科技折页、短视频分镜等通用风格素材，后续高价值单复用。
- 筛选长期优质客户：极少数低价客户后续会有企业批量物料需求，作潜在客户储备。

### 1.4 ★ 最终接单门槛铁则
| 单类 | 用途 | 是否对外交付 | 最低价 |
|---|---|---|---|
| 40~80 元低价单 | **仅内部模拟训练** | ❌ 不交付成品 | 不接真实付费 |
| 零售散单 | 真实付费 | ✅ 交付 | **¥300 起** |
| 企业批量 / 长期合作 | 真实付费 | ✅ 交付 | 面议（按量阶梯） |

> **红线**：低价聊天截图、需求素材仅用于 WorkBuddy + 三工作树模拟跑通流水线，**不对外交付成品**。

## 二、分层报价模板

### 2.1 演练档（40~80 元 · 内部）
- 用途：流程跑通、提示词沉淀、话术训练。
- 报价：不对外，仅内部成本测算。
- 交付：仅落盘项目 `outputs/` 与 `fleet_exchange/results/`，不发送给客户。

### 2.2 零售档（¥300 起 · 真实付费）
| 品类 | 基础交付 | 建议报价 | 修改次数 |
|---|---|---|---|
| 单张宣传海报 | 1 主视觉 + 1 文案 | ¥300~600 | 1 次 |
| 画册/折页（≤8P） | 排版 + 文案 + 源文件 | ¥600~1500 | 2 次 |
| 短视频物料包 | 封面 + 3 张分镜图 + 文案 | ¥400~800 | 1 次 |
- 超范围（加页、加版本、商用授权）单独计费，事前确认。

### 2.3 企业批量 / 长期合作档（面议）
- 按月 / 按量阶梯计价，例：月包 ≥10 单享 8 折，专属素材库归客户。
- 必须签简单书面确认（微信文字确认亦可），明确版权授权范围（个人非商用 / 企业商用）。

## 三、客户沟通与纠纷应对话术（接单前必发）

> 原则：**权责前置，接单前把边界同步客户，杜绝售后扯皮。**

### 3.1 接单前确认模板（发客户）
```
您好，确认一下本次需求：
1. 交付物：______（具体数量+规格）
2. 报价：¥______（含 __ 次修改）
3. 修改规则：超出次数按 ¥__/次 计费
4. 版权：交付物为原创设计，风格参考您提供的样例；商用授权范围：______（个人非商用 / 企业商用）
5. 工期：__ 个工作日内
确认后开始，谢谢~
```

### 3.2 常见风险应对话术
| 场景 | 应对话术 |
|---|---|
| 客户要求"免费多改几版" | "本次含 __ 次修改已包含在报价内，额外版本按 ¥__/版 计费，您看需要加几版？" |
| 中途大幅变更需求 | "需求变更属于新增范围，需补 ¥__ 并顺延 __ 天工期，确认后我继续。" |
| 客户反悔不付尾款 | "按接单确认，成品已按约定交付，请于 __ 日前结清尾款 ¥__；逾期未结将暂停后续合作。" |
| 直接要源文件/工程文件 | "源文件含 ¥__ 授权费（或已含在批量档），确认后发送。" |
| 要求照搬某知名海报/Logo | "可以借鉴风格，但不能直接使用原素材/标识（版权红线），我按风格重做原创版，您看可以吗？" |

### 3.3 纠纷升级规则
1. 初级：话术前置化解（3.2 表）。
2. 中级：暂停交付，WorkBuddy 拉通 Hermes 复盘需求边界，给客户书面澄清。
3. 高级：终止合作，已付定金不退不补，未付尾款催收；重大版权风险立即下架成品。

---

## 四、版权与授权边界（Claude 核查层强制项）
1. 所有交付成品区分**个人非商用 / 企业商用**授权范围，合同/确认文字载明。
2. 风格借鉴 ≠ 素材复制：禁止直接抠原图、字体文件、第三方 Logo、受版权图库素材。
3. 交付物标注「原创设计，风格参考客户提供样例」，企业商用需客户提供素材授权证明。
4. 高风险类目（名人肖像、品牌联名、影视 IP）默认不接。

---

## 五、算力与存储隔离规则（兜底约束）
1. **算力隔离**：模拟演练任务与真实付费大单分开调度；低价模拟不得抢占高价值订单的模型 / 端口资源（演练走 mimo-bridge / ollama-bridge，不烧 Hy3 积分）。
2. **磁盘规范**：项目本体存 E 盘；全部模型缓存、临时输出落 G 盘，不占 C 盘系统空间。
3. **数据备份**：每 2 小时自动同步项目源码 / 素材 / 模板至 GitHub 私有仓 `wework-custom-orders`（gh-proxy 通道）。
