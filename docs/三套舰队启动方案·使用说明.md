## 二、使用方法

### 2.1 一键拉起MIMO

**你说**：`一键拉起mimo` 或 `启动mimo` 或 `mimo舰队`

**我做**：
1. 检查MIMO代理（15721端口）
2. 设置MIMO环境变量
3. 启动Hermes + Claude Code
4. 输出：MIMO V2.5 Pro舰队已启动

**适用场景**：
- 客户接单看截图
- K线图分析
- 海报/图文解析
- 视频素材分析

### 2.2 一键拉起Ollama DeepSeek

**你说**：`一键拉起ollama` 或 `启动deepseek` 或 `ollama舰队`

**我做**：
1. 检查Ollama服务（11434端口）
2. 检查系统内存
3. 设置DeepSeek环境变量
4. 启动Hermes + Claude Code
5. 输出：Ollama Cloud DeepSeek舰队已启动

**适用场景**：
- 量化策略开发
- 批量回测
- 代码编写
- 长上下文任务

### 2.3 一键拉起云原生DeepSeek

**你说**：`一键拉起云原生` 或 `启动云原生deepseek` 或 `云原生舰队`

```
输入类型判断
    ↓
┌─────────────────────────────────────┐
│  文本输入 → DeepSeek（推理）        │
│  图片输入 → MIMO（视觉解析）        │
│  混合输入 → MIMO（图文）+ DS（推理）│
└─────────────────────────────────────┘
    ↓
输出合并
```

## 六、自动降级容错

Ollama Cloud返回429/503时，自动切换到官方DeepSeek API：

```
Ollama Cloud API调用
    ↓
┌─────────────────────────────────────┐
│  成功 → 返回结果                    │
│  429  → 自动切官方DS API重试        │
│  503  → 自动切官方DS API重试        │
│  其他  → 报错终止                   │
└─────────────────────────────────────┘
    ↓
重试成功 → 返回结果
重试失败 → 报错终止
```

## 八、常见问题

### 8.1 一键拉起后没有反应
- 检查代理端口是否运行（15721、15730）
- 检查Ollama服务是否运行（B方案）

### 8.2 DeepSeek API调用失败
- 检查API Key是否正确
- 检查网络连接
- 确认免费额度是否用完

### 8.3 视觉任务失败
- 确认MIMO代理是否运行
- 检查MIMO额度是否到期
