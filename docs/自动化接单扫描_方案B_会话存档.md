# 自动化接单扫描 · 方案B（企业微信会话存档 API）实施框架

> 版本：v1.0 | 创建：2026-08-13 | 归属：企业微信群定制接单项目
> 关联：`scripts/wecom_order_monitor.py`（方案A 本地附件轮询，已落地可跑）

## 一、背景

用户要求「自动化扫描企业微信群接单」。实测结论（已记录）：

- 企微客户端（WXWork.exe）在运行，但消息库为 **SQLCipher 加密**，本地不可直读；
- 个人版无开放读群 API，本地逆向解密违规且易碎（不推荐）；
- **唯一合规正路 = 企业管理员开通「会话存档」官方 API**，授权拉取群消息。

## 二、方案B 链路（会话存档 API）

```
企业微信管理后台开通「会话存档」+ 配置可信 IP
  → 拉取群消息（消息 ID / 内容 / 时间 / 发送人）
  → 关键词过滤（扣1 / task / 接单 / 任务编号）
  → 命中 → 复用 scripts/wecom_order_monitor.py 的建档逻辑生成任务卡草案
  → 大脑复核 → 正式建档走流水线
```

## 三、前置条件（需 owner 在企业微信后台操作，Agent 无权限）

| # | 动作 | 位置 |
|---|------|------|
| 1 | 开通「会话存档」 | 企业微信管理后台 → 管理工具 → 会话内容存档 |
| 2 | 配置可信 IP | 同上（拉取接口需服务器白名单） |
| 3 | 获取 Secret + 公钥 | 后台生成，密钥走环境变量，禁止写死 |
| 4 | 安装企微会话存档 SDK | 官方 Python SDK：`wxcryptopy` 或官方下载包 |
