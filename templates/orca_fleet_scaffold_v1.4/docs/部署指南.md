# ORCA 舰队脚手架部署指南（v1.4）

> 把 codex / claude-code 云上 NPC + 本机三工作树 + Maris 调度接入，一键统一部署到所有 ORCA 项目。

## 一、模板位置

```
templates/orca_fleet_scaffold_v1.4/
├── .cnb.yml                  # CNB NPC 事件绑定（codex / claude-code / $ 兜底）
├── .cnb/settings.yml         # NPC 角色定义（通用版，可个性化）
├── .orca/setup.sh            # ORCA 打开项目自动就绪（代理拉起）
├── CODEX.md / CLAUDE.md      # 本机 Codex / Claude Code 会话自动恢复指令
├── scaffold_version          # 脚手架版本号
├── 脚手架README.md            # 脚手架说明
├── fleet_exchange/           # 任务卡流转区模板
└── scripts/
    ├── apply_scaffold.sh     # ★ 一键批量部署脚本（核心入口）
    ├── orca_setup_worktree.sh    # 工作树环境注入
    ├── orca_project_startup.sh   # 项目自动就绪检查
    ├── orca_init_worktrees.sh    # 三工作树一键初始化
    ├── maris_dispatch.sh         # Maris 任务卡投递
    └── maris_gen_readme.sh       # 生成 Maris 接入说明
```

## 二、一键部署（核心步骤）

在本机 Git Bash（或 ORCA 终端）执行：

```bash
# 方式一：指定项目目录部署
bash templates/orca_fleet_scaffold_v1.4/scripts/apply_scaffold.sh \
    "E:/龙虾AI主控中心/我的AI分身/CODEX量化策略20260615/币安/我的黑马策略"

# 方式二：一次部署多个项目
bash templates/orca_fleet_scaffold_v1.4/scripts/apply_scaffold.sh \
    "E:/.../项目A" "E:/.../项目B" "E:/.../项目C"

# 方式三：部署脚本内置的默认项目列表（可自行编辑 DEFAULT_PROJECTS）
bash templates/orca_fleet_scaffold_v1.4/scripts/apply_scaffold.sh --all
```

脚本行为：
- **幂等**：已存在的文件一律跳过（`[SKIP]`），不会覆盖你已有的配置
- 自动补齐：`.cnb.yml`、`.cnb/settings.yml`、`.orca/setup.sh`、`CODEX.md`、`CLAUDE.md`、`scripts/*.sh`、`fleet_exchange/` 目录、`脚手架README.md`、`scaffold_version`

## 三、部署后初始化（每个项目执行一次）

```bash
cd <项目根目录>
# 1. 初始化三工作树（hermes/brain + codex/executor + claude/reviewer）
bash scripts/orca_init_worktrees.sh

# 2. 在每个工作树「添加设置脚本」框粘贴一行命令
bash ../../scripts/orca_setup_worktree.sh

# 3. 生成 Maris 接入说明
bash scripts/maris_gen_readme.sh

# 4. 提交并推送
git add -A && git commit -m "feat: 配置 CNB NPC + ORCA 多 Agent 脚手架"
git push
```

## 四、部署后如何使用

### 4.1 召唤云上 NPC（CNB 平台）

在 CNB 仓库的 Issue / PR 评论区 @（**必须用完整格式**，简写不生效）：

```text
@TJF19770107/<项目名>(codex) 帮我写一个 Python 脚本...
@TJF19770107/<项目名>(claude-code) 请审计上面的代码
@CodeBuddy 做最终审查
```

> 记得勾选评论区下方「替我上班」（需仓库开发者及以上权限）。

### 4.2 Maris 一键调度

```bash
bash scripts/maris_dispatch.sh "朋友圈餐饮海报，露营烤肉套餐198元"
bash scripts/maris_dispatch.sh --type poster --desc "开业大吉" --price 300
```

任务卡会写入 `fleet_exchange/incoming/`，舰队自动接单，流转 `incoming → doing → done → results`。

### 4.3 本机三 Agent

- `worktrees/hermes`（大脑层）：需求拆解、任务编排
- `worktrees/codex`（执行层）：代码实现、物料生成
- `worktrees/claude`（审核层）：质量校验、合规把关

- 部署脚本**不会覆盖**你已有的 CODEX.md / CLAUDE.md / settings.yml / scaffold_version（遵循版本治理：一致即静默，不强制升级）

- `fleet_exchange/` 运行时文件不入 Git（.gitignore 已处理），只提交 .gitkeep
