## 三、执行工作流（全链路 MiMo V2.5，零额外费用）

### 阶段1：需求抓取（自动化）
```
企业微信群截图 → OCR文字识别(RapidOCR) → 结构化JSON
```
- 工具：RapidOCR（本地运行，零费用）
- 输出：`fleet_exchange/parsed/订单XXX.json`

### 阶段2：需求评估（MiMo V2.5）
```
结构化需求 → MiMo分析难度/时间/报价 → 生成接单建议
```
- 模型：mimo-v2.5-pro（已有API，零额外费用）
- 阈值：自动过滤10元以下订单

### 阶段3：设计执行（分链路）

| 需求类型 | 执行引擎 | 工具 |
|----------|----------|------|
| AI生图类 | Codex → MiMo图像生成 | ComfyUI / MiMo Image |
| 图文排版类 | Hermes → 模板套图 | Python PIL + 模板库 |
| 复杂设计 | 人工队列 | Photoshop + 设计师 |

### 阶段4：质检交付
```
自动检查：尺寸/分辨率/色彩模式/文件格式
人工抽检：5分钟快速审核
交付：私聊客服，附源文件+预览图
```
