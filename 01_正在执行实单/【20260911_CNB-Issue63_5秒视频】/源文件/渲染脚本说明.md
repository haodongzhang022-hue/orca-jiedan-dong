# 渲染脚本说明

| 脚本 | 作用 |
|---|---|
| `scene.py` | 古风书房场景（墙面/格窗/书架/挂轴/地板/长案/笔架砚台）+ 柔和光束 |
| `character.py` | 人物分层：身体（呼吸）、头发后层、头部（静态五官）、眼睛、嘴、刘海前层 |
| `render.py` | 120 帧微动合成 + 运镜缓推 + 4x 超采样降采样 |
| `verify.py` | 13 项交付硬校验 |

复现命令：
```bash
python3 render.py <订单目录>
ffmpeg -y -framerate 24 -start_number 0 -i <订单目录>/源文件/frames/f%04d.png \
  -frames:v 120 -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p \
  -movflags +faststart -r 24 <订单目录>/交付/国漫条漫_书房青年_5s_1080p24.mp4
python3 verify.py <订单目录>
```

脚本位于仓库 `scripts/gufeng_manju/`。
