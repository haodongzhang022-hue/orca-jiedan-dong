# Design Brief · 宣传单双面 + 12卡片 + 4PPT（¥512 实单）

> 方法论：龙虾五步法 Step1 炼精化气 + Step2 炼气化神

## 一、Step1 炼精化气 · 需求解析

### 1.1 原始需求
企业微信群「平面设计新人接单③群」截图OCR：
- 宣传单双面（正反面设计）
- 卡片 12 张
- PPT 4 张
- 总价：512 元，联系人客服赵敏（19151988012）

### 1.2 设计规格（明确）
| 品类 | 规格 | 数量 | 说明 |
|------|------|------|------|
| 宣传单 | A5（148×210mm）双面，300dpi，出血3mm | 1款2面 | 正面：主视觉+标题+卖点；背面：详情+联系方式 |
| 卡片 | 名片/会员卡 90×54mm 横版，300dpi | 12张 | 统一VI风格，12个主题信息槽位 |
| PPT | 16:9 横版（1920×1080） | 4页 | 封面/目录/内容/尾页，统一VI |

### 1.3 关键约束
- 客户未提供品牌/行业信息 → 采用「通用企业品牌宣传」占位文案（Placeholder），交付时提示客户替换真实内容
- 印刷类：提示终稿转 CMYK、≥300dpi、预留出血
- 合规红线：不盗用第三方 Logo/字体/受版权图库；占位文案不伪造真实公司名

## 二、Step2 炼气化神 · 能力映射

### 2.1 模板/技能匹配
| 需求 | 对应技能 | 模板 |
|------|----------|------|
| 宣传单双面 | 画册折页排版商单 | 折页排版（A5双面） |
| 卡片12张 | 海报设计商单 / 卡片模板 | 宣传卡片模板（90×54mm 批量） |
| PPT 4张 | PPT 制作（python-pptx） | 16:9 统一VI四页模板 |

### 2.2 统一VI设计语言（贯穿三品类）
- 主色：深海蓝 `#0B3C5D` + 活力橙 `#F39C12` + 中性灰 `#E8E8E8`
- 字体：Noto Sans CJK SC（黑体系，现代商务）
- 版式：留白充足、信息层级清晰、几何装饰元素（圆/线条/三角）
- 风格关键词：商务 / 专业 / 活力 / 现代

### 2.3 报价与成本核算
- 报价：¥512（实单，≥300 门槛 → 归 `01_正在执行实单`）
- 成本：本地 SVG/PIL/python-pptx 零积分渲染 + 免费图像适配器降级链路，毛利 ≈ 100%（无外部API消耗）
- 交付：3类源文件（SVG/HTML/PPTX）+ PNG预览 + 交付说明

### 2.4 版权声明模板
「本设计为原创设计，风格参考通用商务范例；占位文案与占位图形仅供版式演示，正式商用请替换为客户真实品牌信息并获得相应素材授权。」

## 三、执行指令（给 Codex / 渲染器）
1. 宣传单正面：主标题区 + 副标题 + 三大卖点 + 行动号召（CTA）+ 联系方式占位
2. 宣传单背面：公司简介占位 + 服务清单 + 地址/电话占位 + 二维码占位
3. 12张卡片：统一版式（Logo占位+标题+副标题+编号），12个主题（服务/产品/活动等）
4. PPT 4页：封面页/目录页/内容页(1)/尾页，统一VI，母版配色一致

## 四、验收标准（Claude Code 终审）
- 印刷规范：宣传单/卡片标注出血、300dpi、CMYK提示
- 信息完整：标题/卖点/联系方式/CTA 槽位齐全
- 统一性：三品类 VI 一致（主色/字体/版式语言）
- 合规：无侵权素材、占位文案明确标注
- 成本：零外部积分消耗，毛利为正
