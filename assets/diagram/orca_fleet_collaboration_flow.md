## 角色权责表格

```
┌────────────┬──────────────────────────────────────────────────────────────────────┐
│ 角色        │ 权责边界                                                             │
├────────────┼──────────────────────────────────────────────────────────────────────┤
│ Maris      │ ✓ 投递任务到 incoming/                                               │
│ (调度中枢)  │ ✓ 刷新 README 状态                                                   │
│            │ ✓ 触发 G 盘镜像                                                       │
│            │ ✗ 禁止直接修改 doing/ 内容                                             │
│            │ ✗ 禁止跳过审核直接归档                                                 │
├────────────┼──────────────────────────────────────────────────────────────────────┤
│ Codex      │ ✓ 从 incoming/ 取任务执行                                             │
│ (执行层)    │ ✓ 执行代码/生成物料/写入 doing/                                        │
│            │ ✗ 禁止自审自通过                                                       │
│            │ ✗ 禁止直接移入 done/                                                   │
├────────────┼──────────────────────────────────────────────────────────────────────┤
│ Claude Code│ ✓ 从 doing/ 取产出审核                                                │
│ (审核层)    │ ✓ 审核校验/移入 done/                                                 │
│            │ ✗ 禁止修改产出内容（仅审核/退回）                                       │
│            │ ✗ 禁止直接归档                                                         │
├────────────┼──────────────────────────────────────────────────────────────────────┤
│ CodeBuddy  │ ✓ 从 done/ 终审并归档到 results/                                      │
│ (终审层)    │ ✓ 提交 PR                                                            │
│            │ ✗ 禁止重新执行任务                                                     │
│            │ ✗ 禁止修改原始产出                                                     │
└────────────┴──────────────────────────────────────────────────────────────────────┘
```

## 触发条件与脚本对照

```
┌─────────────┬──────────────────────┬──────────────────────┬───────────────────────┐
│ 流转节点     │ 触发主体              │ 对应脚本              │ 触发条件               │
├─────────────┼──────────────────────┼──────────────────────┼───────────────────────┤
│ → incoming/ │ Maris                │ maris_dispatch.sh    │ 手动或自动投递         │
│ → doing/    │ Codex (本地或NPC)    │ Codex CLI / @npc     │ incoming/ 有新任务     │
│ → done/     │ Claude Code (本地/NPC)│ Claude CLI / @npc   │ doing/ 有待审核产出    │
│ → results/  │ CodeBuddy            │ fleet_done.sh / @CB  │ done/ 有已审核产出     │
└─────────────┴──────────────────────┴──────────────────────┴───────────────────────┘
```
