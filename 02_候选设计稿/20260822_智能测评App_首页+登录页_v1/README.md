# 智能测评 App · 首页 + 登录页（仅前端界面）

> 交付编号：20260822 | 品类：App 前端 UI | 交付物：HTML + CSS + JS（纯前端）
> 规格：1920 宽适配 · 响应式 · 移动端优先 · 编码 UTF-8

## 交付物清单

| 文件 | 说明 |
|---|---|
| `index.html` | 1️⃣ 首页模块 |
| `login.html` | 2️⃣ 登录页面 |
| `style.css` | 共享样式（浅青绿渐变科技背景 / 卡片布局 / 线性图标） |
| `script.js` | 前端交互（表单校验 / 密码明文切换 / Tab 切换 / 页面跳转） |

> 打开方式：浏览器直接打开 `index.html` 即可预览，无外部依赖。

---

## 1️⃣ 首页模块

- **顶部 slogan**：示例「✨ AI 让学习更高效」
- **App 简介**：卡片布局展示四块能力
  - AI 测评题 · 智能生成专属测评题目
  - 知识巩固 · 针对性复习薄弱知识点
  - 成绩分析 · 可视化学习数据报告
  - 错题本 · 错题自动归纳随时回顾
- **核心按钮**：主按钮「开始测评」（点击后引导登录）
- **底部**：轻量登录 / 注册向导
- **底部导航**：首页 / 测评 / 成绩 / 我的

## 2️⃣ 登录页面（仅前端界面）

- **登录方式**：手机号 + 密码
- **表单校验**：手机号格式校验（11 位大陆号码）、密码明文/隐藏切换、错误提示红字、成功提示绿字
- **Tab 切换**：登录 / 注册 双表单
- **跳转入口**：没有账号 →「立即注册」（切到注册 Tab）
- **返回按钮**：回到 App 首页

## 设计风格

- **背景**：浅青绿渐变科技风（渐变 + 光晕 + 网格科技纹理）
- **UI 组件**：线性图标（内联 SVG）、卡片布局、圆角、柔和阴影
- **整体**：页面干净、现代、通透，主色青绿 `#26b8a3`
