## 文件夹结构

```
数字人视频订单/
├── README.md                    # 本说明文件
├── 订单模板/                     # 标准化模板
│   ├── 对话脚本模板.md           # 文案编写模板
│   ├── 订单登记表.xlsx           # 订单台账
│   └── 报价模板_三档.md          # 对外报价单
├── ORD-20260803-001_测试订单/    # 订单编号格式：ORD-日期-序号
│   ├── 订单信息.md               # 客户需求、报价、交付时间
│   ├── 对话脚本.md               # 本次对话文案
│   ├── 素材/                     # 参考图、音频等
│   │   ├── 男主播.png
│   │   ├── 女主播.png
│   │   └── 背景.png
│   ├── 生成/                     # AI生成的中间文件
│   │   ├── 音频_男.wav
│   │   ├── 音频_女.wav
│   │   └── 原始视频.mp4
│   ├── 成品/                     # 最终交付物
│   │   └── 成品_双人对话_9秒.mp4
│   └── 日志.md                   # 生成参数、耗时、成本记录
├── ORD-20260803-002_正式订单1/   # 后续订单以此类推
│   └── ...
└── 归档/                         # 已完成订单归档
    └── ...
```

## 命名规范

| 项目 | 格式 | 示例 |
|------|------|------|
| 订单编号 | ORD-YYYYMMDD-NNN | ORD-20260803-001 |
| 成品视频 | 成品_双人对话_{时长}秒_{序号}.mp4 | 成品_双人对话_9秒_001.mp4 |
| 音频文件 | 音频_{角色}_{序号}.wav | 音频_男_001.wav |
| 参考图 | {角色}.png | 男主播.png |

## 隔离原则

1. **每个订单独立子文件夹**，互不干扰
2. **素材、生成、成品三级目录**，清晰分离
3. **日志必写**，记录每次生成的参数和成本
4. **完成后归档**，移动到归档/目录
